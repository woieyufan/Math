## 講義體系架構與四大核心支柱

資優數學超越應試死記硬背，聚焦於現代數學思想的四條主脊椎：

| 領域 | 核心研究主題 | 典型競賽/進階思維技巧 |
| :--- | :--- | :--- |
| **數論 (Number Theory)** | 整除性、帶餘除法、同餘系統、不定方程、質數與算術基本定理 | 歐幾里得輾轉相除逆運算、貝祖等式、費馬小定理、歐拉定理、階與原根、勒讓德階乘素因子分解 |
| **代數 (Algebra)** | 多項式理論、高次韋達定理、牛頓和公式、經典不等式鏈 | 對稱多項式基本定理、柯西-施瓦茨幾何向量內積視角、安杜因分式柯西、AM-GM 倒推歸納法 |
| **幾何 (Geometry)** | 塞瓦與梅涅勞斯定理、圓冪定理、根軸系統、四點共圓 | 射影幾何比值乘積守恆、根軸垂直連心線、托勒密定理、幾何反演與旋轉變換降維打擊 |
| **組合 (Combinatorics)** | 鴿籠原理（連續幾何形式）、雙重計數、圖論初階、不變量原理 | 狄利克雷等價分類構造、Fubini 行列統計、圖論握手定理、棋盤染色不變量、半不變量勢能函數 |

## 一鍵自動編譯指南

本專案配備出版級自動編譯引擎。**全域規範遵循「預設不主動生成 PDF」**：
- 預設模式：僅生成高解析度 HTML 白皮書（快速、輕量、含完整 KaTeX 數學渲染）。
- PDF 模式：當傳入 `--pdf` 旗標時，調用 Headless Chrome 列印並透過 PyMuPDF 自動注入 8 處原生互動批註與 16 級側邊書籤目錄。

```bash
# 預設編譯：生成 HTML 典藏白皮書
cd 01_資優數學講義
python build_gifted_math_whitepaper.py

# 若明確需要輸出 PDF（需安裝 google-chrome 與 pymupdf）：
python build_gifted_math_whitepaper.py --pdf
```

輸出文件：
- `中學數理資優思維與奧賽教研白皮書.html`（預設生成）
- `中學數理資優思維與奧賽教研白皮書.pdf`（僅在 `--pdf` 時生成）

## 自學與教學建議指南

1. **從反例與邊界探索**：資優數學題目的第一步並非盲目列式，而是檢視 $n=1, 2, 3$ 的極值行為，尋找規律與不變量。
2. **構造法與對偶思維**：在組合與幾何問題中，學會將無序問題映射至幾何圖形（如將同餘轉化為鐘面幾何，將分配問題轉化為鴿籠模型）。
3. **嚴謹書寫證明**：每一步推導必須有明確的公理、定理依據，杜絕直覺上的跳步。
