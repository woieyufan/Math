# 國中資優數學競賽與深度思維講義庫

本專案收錄完整之資優數學課程講義、奧林匹克試題、希望杯競賽真題、能力情況測驗及完整手寫/官方解析，專為培養中學資優自學者與競賽選手之「抽象思維」、「構造能力」與「嚴密證明力」而建立。

---

## 講義體系架構與四大核心支柱

資優數學超越應試死記硬背，聚焦於現代數學思想的四條主脊椎：

| 領域 | 核心研究主題 | 典型競賽/進階思維技巧 |
| :--- | :--- | :--- |
| **數論 (Number Theory)** | 整除性、帶餘除法、同餘系統、不定方程、質數與算術基本定理 | 歐幾里得輾轉相除、費馬小定理、中國剩餘定理、階與原根 |
| **代數 (Algebra)** | 多項式理論、函數方程、數列遞迴、經典不等式 | 對稱多項式、根與係數、柯西/算幾/排序不等式、柯西 Schwarz |
| **幾何 (Geometry)** | 圓冪定理、四點共圓、共點與共線、射影與變換 | 塞瓦（Ceva）與梅涅勞斯（Menelaus）定理、托勒密定理、反演變換 |
| **組合 (Combinatorics)** | 計數原理、容斥原理、圖論初階、極值原理、不變量原理 | 鴿籠原理（抽屜原理）、染色問題、雙重計數（Double Counting） |

## 自學與教學建議指南

1. **從反例與邊界探索**：資優數學題目的第一步並非列式，而是檢視 $n=1, 2, 3$ 的極值行為，尋找規律與不變量。
2. **構造法與對偶思維**：在組合與幾何問題中，學會將無序問題映射至幾何圖形（如將同餘轉化為鐘面幾何，將分配問題轉化為鴿籠模型）。
3. **嚴謹書寫證明**：每一步推導必須有明確的公理、定理依據，杜絕直覺上的跳步。
