# 第一篇：數論與整數構造 (Number Theory)

數論是「數學的皇后」。中學資優數論的核心任務不是大數運算，而是洞悉離散整數環 $\mathbb{Z}$ 的結構、帶餘分類與因數倍數的深層約束。

## 1. 帶餘除法、歐幾里得輾轉相除與 Bézout 等式

### 1.1 帶餘除法定理 (Division Algorithm)
對任意整數 $a$ 與正整數 $b$，存在唯一整數對 $(q, r)$ 使得：
$$a = bq + r, \quad 0 \le r < b$$
其中 $q$ 稱為商 (Quotient)，$r$ 稱為餘數 (Remainder)。

### 1.2 歐幾里得輾轉相除法 (Euclidean Algorithm)
若 $a = bq + r$，則 $\gcd(a, b) = \gcd(b, r)$。  
**證明**：設 $d \mid a$ 且 $d \mid b$，則 $d \mid (a - bq) = r$，故 $d \mid \gcd(b, r)$；反之同理。由此遞推至餘數為 0，最後的非零餘數即為最大公因數。

### 1.3 貝祖等式 (Bézout's Identity)
設 $a, b \in \mathbb{Z}^+$，則存在整數 $x, y \in \mathbb{Z}$ 使得：
$$ax + by = \gcd(a, b)$$
更進一步，線性不定方程 $ax + by = c$ 有整數解的充要條件為 $\gcd(a, b) \mid c$。

> **【競賽構造思維：逆運算拓展】**  
> 設 $(x_0, y_0)$ 為特解，則通解為：
> $$x = x_0 + k \cdot \frac{b}{\gcd(a, b)}, \quad y = y_0 - k \cdot \frac{a}{\gcd(a, b)}, \quad k \in \mathbb{Z}$$

---

## 2. 同餘算術與環 $\mathbb{Z}_m$ 的結構

### 2.1 同餘的定義與基本性質
若 $m \mid (a - b)$，則記為 $a \equiv b \pmod{m}$。
- 若 $a \equiv b \pmod{m}$ 且 $c \equiv d \pmod{m}$，則 $a \pm c \equiv b \pm d \pmod{m}$，且 $ac \equiv bd \pmod{m}$。
- **除法警告**：$ca \equiv cb \pmod{m} \iff a \equiv b \pmod{\frac{m}{\gcd(c, m)}}$。只有當 $\gcd(c, m) = 1$ 時，才能兩邊同除 $c$。

### 2.2 完全剩餘系與簡化剩餘系
- **完全剩餘系 (CRS)**：包含模 $m$ 下所有餘數各一個的集合，例如 $\{0, 1, 2, \dots, m-1\}$。
- **簡化剩餘系 (RRS)**：完全剩餘系中與 $m$ 互質的元素子集，其元素個數定義為歐拉函數 $\phi(m)$。

---

## 3. 費馬小定理、歐拉定理與原根

### 3.1 費馬小定理 (Fermat's Little Theorem)
若 $p$ 為質數，且 $\gcd(a, p) = 1$，則：
$$a^{p-1} \equiv 1 \pmod{p} \iff a^p \equiv a \pmod{p}$$

### 3.2 歐拉定理 (Euler's Totient Theorem)
對任意正整數 $m$ 及 $\gcd(a, m) = 1$，有：
$$a^{\phi(m)} \equiv 1 \pmod{m}$$
其中歐拉函數公式為：$\phi(m) = m \prod_{p \mid m} \left(1 - \frac{1}{p}\right)$。

### 3.3 階與指數循環 (Order of an Element)
使 $a^d \equiv 1 \pmod{m}$ 成立的最小正整數 $d$ 稱為 $a$ 模 $m$ 的**階**，記作 $\operatorname{ord}_m(a)$。  
**核心性質**：
1. $a^k \equiv 1 \pmod{m} \iff \operatorname{ord}_m(a) \mid k$。
2. 由歐拉定理可知：$\operatorname{ord}_m(a) \mid \phi(m)$。

---

## 4. 算術基本定理與勒讓德公式 (Legendre's Formula)

### 4.1 唯一分解定理 (Fundamental Theorem of Arithmetic)
任意大於 1 的正整數 $n$ 可唯一分解為質數乘積：
$$n = p_1^{\alpha_1} p_2^{\alpha_2} \cdots p_k^{\alpha_k}, \quad p_1 < p_2 < \dots < p_k, \ \alpha_i \ge 1$$
其正因數個數 $d(n) = \prod_{i=1}^k (\alpha_i + 1)$；正因數之和 $\sigma(n) = \prod_{i=1}^k \frac{p_i^{\alpha_i+1}-1}{p_i-1}$。

### 4.2 勒讓德公式 ($p$-進賦值)
階乘 $n!$ 的質因數分解中，質數 $p$ 的最高冪次 $v_p(n!)$ 為：
$$v_p(n!) = \sum_{k=1}^{\infty} \left\lfloor \frac{n}{p^k} \right\rfloor = \left\lfloor \frac{n}{p} \right\rfloor + \left\lfloor \frac{n}{p^2} \right\rfloor + \left\lfloor \frac{n}{p^3} \right\rfloor + \cdots$$
同時具有簡約封閉形式：$v_p(n!) = \frac{n - S_p(n)}{p - 1}$，其中 $S_p(n)$ 為 $n$ 在 $p$ 進制下的各位數之和。

## 5. 數論專題名題詳解

### 範例 1.1：模循環與整除性構造
**【題目】** 求所有正整數對 $(x, y)$ 使得 $3^x + 55 = y^2$。

**【解析】**
1. **模 3 分析**：
   $$y^2 = 3^x + 55 \equiv 0 + 55 \equiv 1 \pmod{3}$$
   對於任意整數 $y$，$y^2 \equiv 0$ 或 $1 \pmod{3}$，此式在模 3 下恒成立，暫無矛盾。
2. **模 4 分析**：
   考慮 $3^x \pmod{4}$：
   $$3^1 \equiv 3 \pmod{4}, \quad 3^2 \equiv 1 \pmod{4}, \quad 3^x \equiv (-1)^x \pmod{4}$$
   又 $55 \equiv 3 \pmod{4}$。平方數 $y^2 \equiv 0$ 或 $1 \pmod{4}$。
   - 若 $x$ 為奇數：$3^x + 55 \equiv (-1) + 3 \equiv 2 \pmod{4}$。但平方數模 4 絕不可能為 2！故 $x$ 必為**偶數**。
3. **因式分解構造**：
   設 $x = 2k$（$k \ge 1$），則原式轉化為：
   $$55 = y^2 - (3^k)^2 = (y - 3^k)(y + 3^k)$$
   因為 $y, k$ 均為正整數，且 $y + 3^k > y - 3^k > 0$。
   55 的正因數分解僅有兩組：$(1, 55)$ 與 $(5, 11)$。
   - **情況 A**：$\begin{cases} y + 3^k = 55 \\ y - 3^k = 1 \end{cases} \implies 2 \cdot 3^k = 54 \implies 3^k = 27 \implies k = 3, y = 28$。此時 $x = 2k = 6$。
   - **情況 B**：$\begin{cases} y + 3^k = 11 \\ y - 3^k = 5 \end{cases} \implies 2 \cdot 3^k = 6 \implies 3^k = 3 \implies k = 1, y = 8$。此時 $x = 2k = 2$。
4. **驗算與結論**：
   - 當 $(x, y) = (2, 8)$ 時：$3^2 + 55 = 9 + 55 = 64 = 8^2$（成立）。
   - 當 $(x, y) = (6, 28)$ 時：$3^6 + 55 = 729 + 55 = 784 = 28^2$（成立）。  
   故所有正整數解為 $(x, y) \in \{(2, 8), (6, 28)\}$。證畢。

# 第二篇：代數結構與不等式分析 (Algebra)

中學競賽代數的精華在於「對稱性」與「不等式鏈」。掌握多項式根與係數的全局結構，以及向量幾何與不等式的內在聯繫，是資優思維的關鍵。

## 1. 韋達定理與對稱多項式基本定理

### 1.1 高次方程韋達定理 (Vieta's Formulas)
設一元 $n$ 次方程 $a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0 = 0$ 的 $n$ 個複數根為 $x_1, x_2, \dots, x_n$。定義初等對稱多項式 $e_k$：
$$e_1 = \sum x_i = -\frac{a_{n-1}}{a_n}, \quad e_2 = \sum_{i<j} x_i x_j = \frac{a_{n-2}}{a_n}, \quad \dots, \quad e_n = x_1 x_2 \cdots x_n = (-1)^n \frac{a_0}{a_n}$$

### 1.2 牛頓和公式 (Newton's Sums)
定義冪和 $p_k = \sum_{i=1}^n x_i^k$。則對於任意 $k \ge 1$：
$$a_n p_k + a_{n-1} p_{k-1} + \dots + a_{n-k+1} p_1 + k a_{n-k} = 0 \quad (1 \le k \le n)$$
牛頓和是求解高次對稱聯立方程與數列遞迴的不二法門。

---

## 2. 經典競賽四大不等式大一統

### 2.1 算術-幾何平均不等式 (AM-GM Inequality)
對任意非負實數 $a_1, a_2, \dots, a_n \ge 0$：
$$\frac{a_1 + a_2 + \dots + a_n}{n} \ge \sqrt[n]{a_1 a_2 \cdots a_n}$$
等號成立當且僅當 $a_1 = a_2 = \dots = a_n$。

### 2.2 柯西-施瓦茨不等式 (Cauchy-Schwarz Inequality)
對任意實數 $a_1, \dots, a_n$ 與 $b_1, \dots, b_n$：
$$\left(\sum_{i=1}^n a_i^2\right) \left(\sum_{i=1}^n b_i^2\right) \ge \left(\sum_{i=1}^n a_i b_i\right)^2$$
**幾何向量視角**：在 $n$ 維歐式空間中，設 $\vec{u} = (a_1, \dots, a_n)$，$\vec{v} = (b_1, \dots, b_n)$。  
內積公式 $\vec{u} \cdot \vec{v} = \|\vec{u}\| \|\vec{v}\| \cos \theta$。因 $|\cos \theta| \le 1$，兩邊平方即得柯西不等式！等號成立當且僅當兩向量共線（即 $\frac{a_1}{b_1} = \frac{a_2}{b_2} = \dots = \frac{a_n}{b_n}$）。

### 2.3 柯西不等式的分式形式（安杜因不等式 / Bergström's Inequality）
對任意實數 $x_1, \dots, x_n$ 及正實數 $y_1, \dots, y_n > 0$：
$$\frac{x_1^2}{y_1} + \frac{x_2^2}{y_2} + \dots + \frac{x_n^2}{y_n} \ge \frac{(x_1 + x_2 + \dots + x_n)^2}{y_1 + y_2 + \dots + y_n}$$
此形式是初等代數解決對稱分式不等式的終極武器。

### 2.4 排序不等式 (Rearrangement Inequality)
設 $a_1 \le a_2 \le \dots \le a_n$ 且 $b_1 \le b_2 \le \dots \le b_n$。若 $(c_1, \dots, c_n)$ 為 $(b_1, \dots, b_n)$ 的任一排列，則：
$$\sum_{i=1}^n a_i b_{n-i+1} \le \sum_{i=1}^n a_i c_i \le \sum_{i=1}^n a_i b_i$$
即：**順序和 $\ge$ 亂序和 $\ge$ 逆序和**。

## 3. 代數專題名題詳解

### 範例 2.1：柯西分式不等式構造
**【題目】** 設 $a, b, c > 0$ 且 $a + b + c = 1$，求證：
$$\frac{a}{b + c} + \frac{b}{c + a} + \frac{c}{a + b} \ge \frac{3}{2} \quad \text{（Nesbitt 不等式）}$$

**【解析】**
1. **分子補全構造**：
   原式左端每項加上 1：
   $$\left(\frac{a}{b+c} + 1\right) + \left(\frac{b}{c+a} + 1\right) + \left(\frac{c}{a+b} + 1\right) = \frac{a+b+c}{b+c} + \frac{a+b+c}{c+a} + \frac{a+b+c}{a+b}$$
   $$= (a+b+c)\left(\frac{1}{b+c} + \frac{1}{c+a} + \frac{1}{a+b}\right)$$
2. **利用柯西分式不等式**：
   $$\frac{1^2}{b+c} + \frac{1^2}{c+a} + \frac{1^2}{a+b} \ge \frac{(1 + 1 + 1)^2}{(b+c) + (c+a) + (a+b)} = \frac{9}{2(a+b+c)}$$
3. **回代原式**：
   $$(a+b+c)\left(\frac{1}{b+c} + \frac{1}{c+a} + \frac{1}{a+b}\right) \ge (a+b+c) \cdot \frac{9}{2(a+b+c)} = \frac{9}{2}$$
   兩邊同時減去 3：
   $$\frac{a}{b + c} + \frac{b}{c + a} + \frac{c}{a + b} \ge \frac{9}{2} - 3 = \frac{3}{2}$$
   等號成立當且僅當 $b+c = c+a = a+b \iff a = b = c = \frac{1}{3}$。證畢。

# 第三篇：競賽幾何與變換思維 (Geometry)

資優幾何超越了課本單一的全等三角形與相似三角形，核心在於掌握射影共線定理、圓方冪系統與剛體/相似變換。

```text
                           幾何大一統架構
            ┌─────────────────────┴─────────────────────┐
            ▼                                           ▼
   【共線與共點定理】                           【圓冪與共圓系統】
  Ceva & Menelaus 定理                        Power of a Point & Radical Axis
            │                                           │
            └─────────────────────┬─────────────────────┘
                                  ▼
                         【幾何變換與反演】
                     Homothety, Inversion & Simson
```

## 1. 塞瓦定理與梅涅勞斯定理

### 1.1 塞瓦定理 (Ceva's Theorem)
在 $\triangle ABC$ 中，點 $D, E, F$ 分別位於邊 $BC, CA, AB$ 上。三條線段 $AD, BE, CF$ 交於同一點 $P$ 的充要條件是：
$$\frac{AF}{FB} \cdot \frac{BD}{DC} \cdot \frac{CE}{EA} = 1$$

### 1.2 梅涅勞斯定理 (Menelaus's Theorem)
若一條直線交 $\triangle ABC$ 的三邊直線 $BC, CA, AB$ 於點 $D, E, F$，則：
$$\frac{AF}{FB} \cdot \frac{BD}{DC} \cdot \frac{CE}{EA} = 1$$
*(注意：此處 $D, E, F$ 中必有 1 個或 3 個點在三角形外延伸線上)*

---

## 2. 圓冪定理與根軸系統

### 2.1 圓冪定理 (Power of a Point)
給定圓 $O$（半徑為 $R$）及平面上一點 $P$。過 $P$ 引任一直線交圓於 $A, B$ 兩點，則乘積：
$$\mathcal{P}(P) = \vec{PA} \cdot \vec{PB} = d^2 - R^2 \quad (d = PO)$$
為一常數，稱為點 $P$ 關於圓 $O$ 的**方冪**。
- 若 $P$ 在圓外，$\mathcal{P}(P) = PT^2$（$PT$ 為切線長）。
- 若 $P$ 在圓內，方冪值為負。

### 2.2 根軸定理 (Radical Axis)
對於兩個不共心的圓 $O_1$ 與 $O_2$，對兩圓方冪相等的點的軌跡為一條與連心線 $O_1O_2$ 垂直的直線，稱為**根軸**。若兩圓相交，根軸即為兩圓的公共弦所在直線。

### 2.3 根心定理 (Radical Center)
三個圓心不共線的圓，兩兩之根軸共點，該點稱為**根心**。

---

## 3. 幾何專題名題詳解

### 範例 3.1：利用塞瓦定理解決中線、角平分線與高線共點
**【題目】** 證明三角形的三條中線、三條角平分線、三條高分別共點（重心 $G$、內心 $I$、垂心 $H$）。

**【解析】**
1. **中線共點（重心）**：
   $D, E, F$ 為三邊中點，則 $AF=FB, BD=DC, CE=EA$。
   $$\frac{AF}{FB} \cdot \frac{BD}{DC} \cdot \frac{CE}{EA} = 1 \cdot 1 \cdot 1 = 1$$
   由塞瓦定理逆定理，三中線必共點於重心 $G$。
2. **內角平分線共點（內心）**：
   設 $AD, BE, CF$ 為內角平分線。由角平分線定理：
   $$\frac{BD}{DC} = \frac{c}{b}, \quad \frac{CE}{EA} = \frac{a}{c}, \quad \frac{AF}{FB} = \frac{b}{a}$$
   相乘得：
   $$\frac{AF}{FB} \cdot \frac{BD}{DC} \cdot \frac{CE}{EA} = \frac{b}{a} \cdot \frac{c}{b} \cdot \frac{a}{c} = 1$$
   由塞瓦定理逆定理，三內角平分線必共點於內心 $I$。
3. **高線共點（垂心）**：
   設 $AD \perp BC, BE \perp CA, CF \perp AB$。
   在直角三角形中：$AF = b \cos A, FB = a \cos B$；$BD = c \cos B, DC = b \cos C$；$CE = a \cos C, EA = c \cos A$。
   代入比值積：
   $$\frac{b \cos A}{a \cos B} \cdot \frac{c \cos B}{b \cos C} \cdot \frac{a \cos C}{c \cos A} = 1$$
   由塞瓦定理逆定理，三高必共點於垂心 $H$。證畢。

# 第四篇：組合數學與離散極值 (Combinatorics)

組合數學是培養創造性思維與非演算法解題的最前線。面對離散有限結構，資優生的四件制勝武器為：**鴿籠原理**、**雙重計數**、**不變量**與**極值法**。

## 1. 狄利克雷抽屜原理（鴿籠原理）的高階構造

### 1.1 連續幾何形式與容積覆蓋
若總測度（面積/長度/角度）為 $M$ 的幾何對象被 $n$ 個子集覆蓋，則至少存在一個子集的測度 $\ge \frac{M}{n}$；同時至少存在兩點的交疊重合密度滿足局部極值。

### 1.2 數論中的鴿籠應用：愛爾特希 (Erdős-Szekeres) 定理
任意長度為 $n^2 + 1$ 的相異實數序列，必包含長度為 $n+1$ 的單調遞增子序列或單調遞減子序列。

---

## 2. 算兩次（Double Counting / Fubini 思想）

### 2.1 雙重計數基本原理
同一個有限集合的計數，從兩個不同的維度（行與列、頂點與邊、人與關係）分別統計，其總量必然恆等：
$$\sum_{x \in X} \deg(x) = \sum_{y \in Y} \deg(y)$$

### 2.2 圖論握手定理 (Handshaking Lemma)
在任意無向圖 $G = (V, E)$ 中，所有頂點的度數之和等於邊數的 2 倍：
$$\sum_{v \in V} \deg(v) = 2|E|$$
**推論**：任何圖中，奇數度的頂點個數必然是**偶數**。

---

## 3. 不變量與半不變量原理 (Invariants & Monovariants)

### 3.1 狀態轉移與不變量
在離散演算法或博弈遊戲中，每一步操作都會改變系統狀態。尋找在任何操作下保持不變的量（如奇偶性、模 $k$ 餘數、代數交叉和、符號乘積），若初始狀態的不變量與目標狀態的不變量不符，則證明**目標狀態不可達**。

### 3.2 半不變量（單調勢能函數）
定義一個映至非負整數的勢能函數 $\Phi(S)$。若每一步操作都保證 $\Phi(S_{t+1}) < \Phi(S_t)$，則此離散進程必然在有限步內終止，且終止狀態必為局部極值。

## 4. 組合專題名題詳解

### 範例 4.1：棋盤覆蓋與奇偶不變量
**【題目】** 一個 $8 \times 8$ 的標準國際象棋棋盤，剪去對角的兩個角落格子（剩餘 62 格）。問：是否能用 31 塊 $1 \times 2$ 的骨牌完全無重疊地覆蓋？

**【解析】**
1. **建立著色幾何模型**：
   將棋盤按黑白相間著色，原 $8 \times 8$ 棋盤有 32 個黑格與 32 個白格。
2. **考察剪去的角落格**：
   剪去的兩個對角格子在同一直線上或對角線上。由於主對角線上所有格子的顏色相同，剪去的兩個格子必為**同色**（設皆為黑格）。
3. **計算剩餘格子顏色分佈**：
   剩餘格子中，黑格有 $32 - 2 = 30$ 個，白格仍有 32 個。
4. **構造骨牌覆蓋不變量**：
   任意一塊 $1 \times 2$ 的骨牌放置於棋盤上，無論橫放還是豎放，必然恰好覆蓋 **1 個黑格與 1 個白格**。
   若 31 塊骨牌能夠完全覆蓋剩餘棋盤，則所覆蓋的黑格總數必為 31，白格總數必為 31。
5. **導出矛盾**：
   棋盤上只有 30 個黑格，但骨牌需要 31 個黑格。矛盾！  
   故不可能用 31 塊骨牌覆蓋該殘缺棋盤。證畢。

# 第五篇：資優班教學法與獨立研究五步法 (Pedagogy & Research)

資優教學的最高境界，不是告訴學生答案，而是設計一個能激發探索慾望的「認知衝突場域」。本篇提煉自《資優數學教材與教法示例》與《國中數學獨立研究第一階段教材》。

## 1. 課堂搭橋式提問法 (Bridging Inquiry Model)

```text
    傳統填鴨教學                  資優搭橋教學
┌──────────────────┐        ┌──────────────────┐
│  給出定理公式    │        │  創設情境遊戲    │（例：因倍數接龍、節稅大作戰）
│        ▼         │        │        ▼         │
│  套用例題計算    │        │  發現策略瓶頸    │（為什麼選 12 會被扣 1+2+3+4+6？）
│        ▼         │        │        ▼         │
│  大量機械刷題    │        │  歸納抽象模型    │（質數保護策略、真因數和 $\sigma(n)-n$）
└──────────────────┘        │        ▼         │
                            │  形式證明與推廣  │（反例檢驗、極值優化、編寫研究報告）
                            └──────────────────┘
```

### 1.1 經典教法實例：節稅高手任務 (Tax Optimization)
- **問題情境**：1 到 15 的整數收入卡，總和 120 萬。選某數 $N$ 為收入時，$N$ 的所有尚未使用過的真因數將被政府抽稅。若選取的數沒有任何未使用的真因數，則該數全額充公。
- **資優生思考階梯**：
  1. **第一階（隨機選取）**：憑直覺選大數（如 15、14），發現稅金損失慘重。
  2. **第二階（質數保護）**：先選大質數（如 13、11），稅金只有 1。
  3. **第三階（因數鏈連鎖）**：1 已經在第一次被扣除，後續再選取質數的倍數時，因數 1 不會再被扣！
  4. **第四階（數學建構）**：問題抽象為「在有向無環圖 (DAG) 上最大化自主節點權重」。

## 2. 國中數學獨立研究五部曲 (Five-Stage Independent Research)

培養資優生獨立研究能力，必須遵循結構化的五部曲路徑：

```text
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│ 1.尋找問題  │ ──> │ 2.補足知識  │ ──> │ 3.文獻探討  │ ──> │ 4.問題探究  │ ──> │ 5.研究成果  │
│ Find Focus  │     │ Acquire Know│     │ Literature  │     │ Deep Probe  │     │ Oral/Paper  │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
```

1. **第一步：尋找問題 (Find the Question)**
   - 從日常生活、數學遊戲或既有定理的邊界條件出發。提問：「如果把正三角形改成任意三角形，結論還成立嗎？」「如果是三維空間呢？」
2. **第二步：補足知識 (Acquire Knowledge)**
   - 超越常態課程，主動研讀大學初等數論、線性代數與幾何變換基礎，掌握符號語言。
3. **第三步：文獻探討 (Literature Review)**
   - 檢索全國科展歷屆得獎作品、奧賽真題，確認選題並非已有已知平庸解，尋找推廣空間。
4. **第四步：問題探究與證明寫作 (Inquiry & Proof)**
   - 經歷「特例檢驗 $\to$ 猜想提出 $\to$ 尋找反例 $\to$ 修正猜想 $\to$ 嚴密證明」的完整閉環。
5. **第五步：書面與口頭報告 (Reporting & Presentation)**
   - 撰寫標準學術論文（摘要、引言、定義、引理、主定理、結論），製作簡報並接受同儕質詢。

## 4. 結語：通往現代數學王國的大門

資優數學絕非單純的「競賽提分技巧」，而是培養未來科學家、工程師與思想家必備的**理性嚴謹心智**。掌握四大支柱與獨立研究方法，學生將自如地在抽象概念與具體問題之間穿梭，以數學的第一性原理看透世界的深層規律。
