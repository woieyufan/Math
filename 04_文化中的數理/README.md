# 04_文化中的數理：生活與新聞中的文明專書

**Mathematics & Science in Culture: The Monograph of Civilization in Everyday Life and News**

本目錄為 `woieyufan EDUCATION` 研發的第四大跨學科教育出版專案《文化中的數理：生活與新聞中的文明密碼》（全書六卷、共 37 章＋結語）。本書立足中小學高年級至高中階段讀者的認知階梯，從日常物件、新聞現場與古今文明器物出發，將天文曆法、對稱群論、拓撲紐結、極限微積分思想、進位制與密碼數論編織為一氣呵成的理性史詩。

## 六卷 37 章核心特色

1. **第一卷｜天時與光影（第 01～04 章）**：從十二時辰、月相盈虧、北斗旋轉到故宮日晷與冬暖夏涼屋簷正切角。
2. **第二卷｜生活幾何、對稱拓撲與益智器物（第 05～10 章）**：涵蓋二面體群與一刀剪、準晶非週期密鋪與彭羅斯黃金比例反證、七巧板 $\sqrt{2}$ 網格與 13 種凸多邊形、三浦折疊與高斯《絕妙定理》、耳機線打結／歐拉七橋／足球 $V-E+F=2$ 必含 12 塊五邊形，以及印加奇普八字結防呆與 Checksum。
3. **第三卷｜度量衡、力學與水利工程（第 11～17 章）**：半斤八兩十六進制二分法、木桿秤、曹沖稱象、商鞅方升公差、應縣木塔斗拱阻尼、趙州石拱橋與歐拉倒懸鏈線，以及都江堰四六分水二次流體力學。
4. **第四卷｜弦圖、圓周率、容積、三角測量與極值前沿（第 18～25 章）**：採「$\sqrt{2}$ 直式開方先行 $\rightarrow \pi$ 割圓術與高斯正十七邊形 $\rightarrow$ 牟合方蓋與祖暅球體積接力 $\rightarrow$ 正切坡度、《海島算經》、舉折飛簷與歐拉公式 $\rightarrow$ 黃鐘律管 vs 秒擺 $g\approx\pi^2 \rightarrow$ 最密堆積、方盒塞硬幣與沙發過彎未解前沿」認知階梯編排。
5. **第五卷｜計算、進位制、演算法與密碼（第 26～32 章）**：洛書幻方、楊輝三角與高斯常態分佈／最小平方法、算籌正負術簡介與算盤五升十進工效學詳述、進位制世界史與「360 vs 365.2422 天體破缺」、陰符密碼、韓信點兵／高斯同餘符號與歐拉 $\varphi(N)$ RSA 公私鑰加密，以及九連環格雷碼。
6. **第六卷｜曆法、天象與時間數論（第 33～37 章）**：天干地支雙齒輪、生辰八字時空坐標、十九年七閏連分數、公曆 400 年 97 閏模 7 閉環（含「進位制不滿足」哲學前瞻與高斯復活節演算法實證 2026 年 4 月 5 日），以及康威末日心算演算法。

## 編譯與驗證指南

### 預設編譯（僅輸出 HTML，嚴格遵守全域規範）

```bash
cd 04_文化中的數理
python3 build_cultural_math_book.py
```

編譯器 `build_cultural_math_book.py` 會自動執行：
- Markdown 公式保護抽取（`\[...\]` 與 `$...$`），防止 HTML 跳脫與標籤截斷；
- `####` 深度子標題（`<h4 class="callout-subhead">`）與 `### 🌌 數理哲學前瞻` 專區盒解析；
- 等寬圖表 `<pre class="book-ascii">`（直式開方、洛書幻方、楊輝三角數塔）排版；
- 左側互動章節目錄（37 章＋結語）與 KaTeX 數學渲染封裝；
- 輸出前自動校驗章節數、數學公式平衡、殘留標記與無 `.pdf` 生成。

### 例外：明確指定 `--pdf` 旗標（需本機具備 Chrome / Chromium）

```bash
python3 build_cultural_math_book.py --pdf
```
