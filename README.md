## 三大專案精粹介紹

### 1. 01_資優數學講義
* **對象**：國中數理資優生、科學班考前培訓、數學奧林匹克選手。
* **特色**：收錄台南市忠孝國中數理資優全學年實體課程檔案、希望杯、奧林匹克真題解析。拒絕機械套題，強調存在性構造（鴿籠原理）、對稱性分析、不變量原理與嚴密形式證明。

### 2. 02_藝術中的數學（美術與音樂）
* **對象**：小學中高年級至國中，尋求跨領域深度連結之自學者與教師。
* **特色**：
  - **美術**：從坐標系寫書法、透視法借位攝影、折紙與多面體角虧損，直通文藝復興名畫幾何解密。
  - **音樂**：從單弦琴與畢氏音差，到二進位節奏網格、Euclidean Rhythms（輾轉相除法生成非洲/拉美節奏）、泛音列 $4:5:6$ 大三和弦、同餘模群 $\mathbb{Z}_{12}$ 與巴哈逆行倒影賦格。

### 3. 03_高中物理化學應用微積分
* **對象**：國三升高一資優超前自學者、高中競賽生、大學理工先修者。
* **特色**：徹底打破「高中死背物理化學經驗公式、大一才學微積分」的荒謬斷層。立足第一性原理，用微積分作為通用語言，一以貫之推導運動學、拉格朗日力學、常微分方程、熱力學、交流電、化學動力學反應速率與常態分佈。

## 快速上手與編譯指南

### 環境依賴
- Python 3.9+
- 推薦套件：`PyMuPDF (fitz)`
  ```bash
  pip install pymupdf
  ```
- PDF 出版編譯需安裝 Google Chrome（支援 headless 模式）。

### 常用編譯指令
```bash
# 編譯《小學全域：美術中的數學白皮書》PDF
cd 02_藝術中的數學_美術與音樂/美術中的數學
python build_art_math_pdf.py

# 編譯《看見幾何》科普專著
python build_geometry_book.py
```
