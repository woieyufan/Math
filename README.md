## 四大專案精粹介紹

### 1. 01_資優數學講義
* **對象**：國中數理資優生、科學班考前培訓、數學奧林匹克選手、資優班指導教師。
* **特色**：收錄台南市忠孝國中數理資優全學年實體課程檔案、希望杯、奧林匹克真題解析。建立四大支柱（數論、代數、幾何、組合）核心手冊，並以 Headless Chrome + PyMuPDF 全自動編譯輸出 16 頁典藏白皮書（含原生互動教育批註）。

### 2. 02_藝術中的數學（美術與音樂）
* **對象**：小學中高年級至國中，尋求跨領域深度連結之自學者與教師。
* **特色**：
  - **美術**：從坐標系寫書法、透視法借位攝影、折紙與多面體角虧損，直通文藝復興名畫幾何解密。
  - **音樂**：從單弦琴與畢氏音差，到二進位節奏網格、Euclidean Rhythms（輾轉相除法生成非洲/拉美節奏）、泛音列 $4:5:6$ 大三和弦、同餘模群 $\mathbb{Z}_{12}$ 與巴哈逆行倒影賦格；單冊《聽見數字》統一專著貫通五大歷史時期與流行和聲。

### 3. 03_高中物理化學應用微積分
* **對象**：國三升高一資優超前自學者、高中競賽生、大學理工先修者。
* **特色**：徹底打破「高中死背物理化學經驗公式、大一才學微積分」的荒謬斷層。立足第一性原理，用微積分作為通用語言，一以貫之推導運動學、微元法代表性契約與半圓重心（Ch 7 $\to$ 10 $\to$ 12）、拉格朗日力學、常微分方程、熱力學、麥克斯韋電磁統一架構（位移電流與光速 $c = 1/\sqrt{\mu_0\varepsilon_0}$）、交流電、化學動力學反應速率與常態分佈。

### 4. 04_文化中的數理（生活與新聞中的文明專書）
* **對象**：中小學高年級至高中自學者、跨領域通識教師、數理文化與科普愛好者。
* **特色**：全書六卷共 37 章（另附結語），每章均採「新聞與生活現場」「文明故事與器物構造解密」「核心數理模型」「動手算術題與解答」四模組展開。橫跨十二時辰與日晷、二面體群與一刀剪、準晶彭羅斯反證、七巧板 13 凸多邊形、三浦折疊與高斯《絕妙定理》、歐拉七橋與足球 12 五邊形、印加奇普八字結、十六兩古秤、都江堰水利、$\sqrt{2}$ 直式開方、劉徽割圓術／牟合方蓋與祖暅求球體積接力、正切坡度與歐拉公式、黃鐘律管 vs 秒擺 $g\approx\pi^2$、最密堆積／方盒塞硬幣／搬沙發過彎前沿、洛書、楊輝三角與高斯常態分佈、算盤五升十進工效學、進位制與 365.2422 天體破缺、韓信點兵／歐拉 RSA 加密，以及十九年七閏、400 年 97 閏模 7 閉環與康威末日演算法。

## 快速上手與編譯指南

### 環境依賴
- Python 3.9+
- 推薦套件：`PyMuPDF`
  ```bash
  pip install pymupdf
  ```
- PDF 出版編譯需安裝 Google Chrome 或 Chromium（支援 headless 模式）。

### 常用編譯指令
```bash
# 編譯《中學數理資優思維與奧賽教研白皮書》HTML（預設不主動生成 PDF）
cd 01_資優數學講義
python3 build_gifted_math_whitepaper.py

# 若明確需輸出 PDF，傳入 --pdf 旗標：
python3 build_gifted_math_whitepaper.py --pdf

# 編譯《文化中的數理：生活與新聞中的文明密碼》37 章數位專書 HTML（預設純 HTML）
cd 04_文化中的數理
python3 build_cultural_math_book.py

# 編譯《小學全域：美術中的數學白皮書》PDF（專案二）
cd 02_藝術中的數學_美術與音樂/美術中的數學
python3 build_art_math_pdf.py

# 編譯《看見幾何》科普專著（專案二）
cd 02_藝術中的數學_美術與音樂/美術中的數學
python3 build_geometry_book.py
```
