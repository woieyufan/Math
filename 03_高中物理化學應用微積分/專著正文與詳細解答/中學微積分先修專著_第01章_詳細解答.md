### 例題 1 解答

#### 題幹目標
已知函數 $f(x) = x^2$，求曲線在點 $(1, 1)$ 處的切線斜率，並寫出該點的切線方程式。

#### 嚴密推演步驟（微積分求切線標準五步法）
第一步【確認目標與切點】：
題目要求在點 $(1, 1)$ 處求切線斜率與切線方程式。已知母函數為 $f(x) = x^2$，切點坐標為 $(x_0, y_0) = (1, 1)$。

第二步【列出導函數定義式】：
寫出微積分通用的導函數定義式：
$$f'(x) = \lim_{\Delta x \to 0} \frac{f(x + \Delta x) - f(x)}{\Delta x}$$

第三步【代入展開約分求導函數】：
將已知函數 $f(x) = x^2$ 直接代入導函數公式中：
$$f'(x) = \lim_{\Delta x \to 0} \frac{(x + \Delta x)^2 - x^2}{\Delta x}$$
展開分子並化簡：
$$\frac{(x + \Delta x)^2 - x^2}{\Delta x} = \frac{x^2 + 2x\Delta x + (\Delta x)^2 - x^2}{\Delta x} = \frac{2x\Delta x + (\Delta x)^2}{\Delta x}$$
因為自變量增量滿足非零前提 $\Delta x \neq 0$，進行安全約分：
$$\frac{2x\Delta x + (\Delta x)^2}{\Delta x} = 2x + \Delta x$$
施加極限運算（$\Delta x \to 0$）：
$$f'(x) = \lim_{\Delta x \to 0} (2x + \Delta x) = 2x + 0 = 2x$$
求得二次函數 $x^2$ 的導函數為 $f'(x) = 2x$。

第四步【計算目標點切線斜率】：
將目標點橫坐標 $x_0 = 1$ 代入求得的導函數中，得到切線斜率：
$$m = f'(1) = 2(1) = 2$$

第五步【點斜式寫出切線方程式】：
由國中點斜式寫出通過點 $(1, 1)$ 且斜率為 $2$ 的切線方程式：
$$y - 1 = 2(x - 1) \implies y = 2x - 1$$

【幾何檢驗與代數全域證明】：
1. 數值抽樣檢驗：
   - 當 $x = 1$ 時：曲線高度 $y = 1^2 = 1$，直線高度 $y = 2(1) - 1 = 1$，兩者重合於點 $(1, 1)$。
   - 當 $x = 0.9$（切點左側）時：曲線高度 $0.81 >$ 直線高度 $0.80$。
   - 當 $x = 1.1$（切點右側）時：曲線高度 $1.21 >$ 直線高度 $1.20$。
2. 代數全域證明：
   考察曲線與切線的高度差函數：
   $$D(x) = f(x) - y_{\text{line}} = x^2 - (2x - 1) = x^2 - 2x + 1 = (x - 1)^2$$
   根據實數完全平方式性質，對於任意實數 $x \neq 1$，恆有 $(x - 1)^2 > 0$；僅在 $x = 1$ 時高度差為 0。
   這給出了嚴密的幾何結論：整條拋物線在接觸點 $(1, 1)$ 兩側全域嚴格高於直線。直線在底部支撐著拋物線，且兩者相交於二重根 $x = 1$（判別式 $\Delta = 0$），精確證明該直線為二次拋物線在該點的切線。

### 例題 2 解答

#### 題幹目標
設自由落體的位置函數為 $s(t) = 4.9t^2$（距離單位為公尺，時間單位為秒）。
1. 依照極限定義，推導物體在第 2 秒末（$t = 2$）那一瞬間的精確瞬時速度。
2. 【工程量測檢驗】現實中的高速攝影機與雷達測速儀在硬體上無法實現 $\Delta t = 0$ 的數學極限，只能在極短間隔（如 $\Delta t = 0.001$ 秒）內記錄位移並計算平均速度。試計算此時儀器測得的平均速度，並以第 1 小問求出的精確瞬時速度為基準真值，評估量測儀器的誤差大小與實用意義。

#### 嚴密推演步驟
第一步：依據極限定義式求精確瞬時速度。
從時間 $t = 2$ 到鄰近時刻 $t = 2 + \Delta t$，計算位移淨增量：
$$\Delta s = 4.9(2 + \Delta t)^2 - 4.9(2)^2 = 4.9\left(4 + 4\Delta t + (\Delta t)^2\right) - 19.6 = 19.6\Delta t + 4.9(\Delta t)^2 \text{ 公尺}$$
計算平均速度表達式（$\Delta t \neq 0$）：
$$\bar{v} = \frac{\Delta s}{\Delta t} = \frac{19.6\Delta t + 4.9(\Delta t)^2}{\Delta t} = 19.6 + 4.9\Delta t \text{ 公尺/秒}$$
施加極限運算，求得第 2 秒末的精確瞬時速度：
$$v(2) = \lim_{\Delta t \to 0} (19.6 + 4.9\Delta t) = 19.6 \text{ 公尺/秒}$$

第二步：以微積分理論檢驗工程量測誤差。
在工程現實中，物理感測器與測速儀器永遠無法真正取極限（硬體不可能在零秒內量出位移），儀器實際上測量的是微小時間段內的平均速度 $\bar{v}$。
當儀器採樣的時間間隔為 $\Delta t = 0.001$ 秒時，測速儀器測得的讀數為：
$$\bar{v} = 19.6 + 4.9(0.001) = 19.6 + 0.0049 = 19.6049 \text{ 公尺/秒}$$
以第 1 小問精確推導出的瞬時速度 $v(2) = 19.6\text{ 公尺/秒}$ 為真值基準，測量誤差為：
$$\text{絕對誤差} = |\bar{v} - v(2)| = 4.9\Delta t = 0.0049 \text{ 公尺/秒}$$
$$\text{相對誤差} = \frac{0.0049}{19.6} = 0.00025 = 0.025\% \text{（萬分之二點五）}$$
【結論用途說明】：
這項分析回答了現實工程的關鍵問題：為什麼交警的測速雷達與高鐵感測器可以用「極短時間的平均速度」代表「瞬間速度」？
因為微積分為物理儀器提供了理論保證：誤差項 $4.9\Delta t$ 隨時間間隔嚴格線性縮小。只要儀器的快門或採樣間隔小於千分之一秒，測量誤差就低於萬分之三，完全滿足工程精度與法律執法標準。微積分的極限定義，正是現實量測技術可靠性的理論基石。

#### 量綱審查
位移增量 $[\Delta s] = \text{m}$，時間增量 $[\Delta t] = \text{s}$。
平均速度 $[\bar{v}] = [\Delta s] / [\Delta t] = \text{m/s}$。
極限瞬時速度 $[v(2)] = \text{m/s}$。
誤差項 $[4.9\Delta t] = (\text{m/s}^2) \times \text{s} = \text{m/s}$。
各項量綱在物理代數上嚴格自洽。

### 例題 3 解答

#### 題幹目標
在手邊沒有計算機的情況下，利用 1.5 節建立的「以直代曲」局部線性逼近公式，手算估計 $\sqrt{101}$ 的近似數值，並透過平方逆運算檢驗其精確度。

#### 嚴密推演步驟
第一步：列出母體函數並依導函數公式求導數。
選取平方根函數 $f(x) = \sqrt{x}$（自變量限制在定義域內部 $x > 0$）。
依據導函數公式，求其導數：
$$f'(x) = \lim_{\Delta x \to 0} \frac{\sqrt{x + \Delta x} - \sqrt{x}}{\Delta x}$$
將分子進行有理化，分子與分母同乘以 $(\sqrt{x + \Delta x} + \sqrt{x})$：
$$\frac{(\sqrt{x + \Delta x} - \sqrt{x})(\sqrt{x + \Delta x} + \sqrt{x})}{\Delta x(\sqrt{x + \Delta x} + \sqrt{x})} = \frac{(x + \Delta x) - x}{\Delta x(\sqrt{x + \Delta x} + \sqrt{x})} = \frac{\Delta x}{\Delta x(\sqrt{x + \Delta x} + \sqrt{x})}$$
因為 $\Delta x \neq 0$，約分消去 $\Delta x$：
$$\frac{1}{\sqrt{x + \Delta x} + \sqrt{x}}$$
施加極限運算（$\Delta x \to 0$）：
$$f'(x) = \lim_{\Delta x \to 0} \frac{1}{\sqrt{x + \Delta x} + \sqrt{x}} = \frac{1}{\sqrt{x} + \sqrt{x}} = \frac{1}{2\sqrt{x}}$$

第二步：選取基準點與增量。
在 $101$ 附近選取最容易開平方的整數作為基準點 $x_0 = 100$。
此時基準值為 $f(100) = \sqrt{100} = 10$。
自變量的偏離增量為 $\Delta x = 101 - 100 = 1$。
在基準點處，切線斜率為：
$$f'(100) = \frac{1}{2\sqrt{100}} = \frac{1}{20} = 0.05$$

第三步：代入局部線性逼近展開式。
$$\sqrt{101} \approx f(100) + f'(100)\Delta x = 10 + 0.05 \times 1 = 10.05$$

第四步：檢驗手算結果的精確度與殘差分析。
將估算值 $10.05$ 進行平方逆運算：
$$(10.05)^2 = 101.0025$$
平方反向殘差為：
$$(10.05)^2 - 101 = 101.0025 - 101 = 0.0025 = \frac{25}{10000} \text{（萬分之二十五）}$$
根據微分關係 $d(y^2) = 2y\,dy$，當 $y \approx 10$ 時有 $\Delta(y^2) \approx 20\,\Delta y$。
因此平方殘差約為開方誤差的 20 倍。
手算估計值 $10.05$ 與 $\sqrt{101}$ 的真實絕對誤差僅約為：
$$|\Delta y| \approx \frac{0.0025}{20} = 0.000125 \text{（萬分之一點二五）}$$
真實值為 $\sqrt{101} \approx 10.0498756$，實際絕對誤差為 $|10.05 - 10.0498756| \approx 0.0001244$，相對誤差僅約百萬分之十二點四，展現出一階線性逼近的極高精度。

### 基礎切線五步法演練

#### 習題 1.1 解答
**題目**：依照例題 1 的標準解題五步法，求一次函數 $f(x) = 3x - 5$ 在 $x = 2$ 處的切線斜率，並說明推導結果與國中學過的直線斜率有何關係。

**詳細推演步驟（微積分求切線標準五步法）**：
* 第一步【確認目標與切點】：
  母函數為一次函數 $f(x) = 3x - 5$。在 $x_0 = 2$ 處，函數值為 $y_0 = f(2) = 3(2) - 5 = 1$。切點坐標為 $(2, 1)$。
* 第二步【列出導函數定義式】：
  $$f'(x) = \lim_{\Delta x \to 0} \frac{f(x + \Delta x) - f(x)}{\Delta x}$$
* 第三步【代入展開約分求導函數】：
  $$f'(x) = \lim_{\Delta x \to 0} \frac{[3(x + \Delta x) - 5] - (3x - 5)}{\Delta x} = \lim_{\Delta x \to 0} \frac{3x + 3\Delta x - 5 - 3x + 5}{\Delta x} = \lim_{\Delta x \to 0} \frac{3\Delta x}{\Delta x}$$
  因為 $\Delta x \neq 0$，約分後取極限：
  $$f'(x) = \lim_{\Delta x \to 0} 3 = 3$$
* 第四步【計算目標點切線斜率】：
  由於導函數恆等於常數 $3$，在 $x_0 = 2$ 處，切線斜率為：
  $$m = f'(2) = 3$$
* 第五步【點斜式寫出切線方程式】：
  通過點 $(2, 1)$ 且斜率為 $3$ 的切線方程式為：
  $$y - 1 = 3(x - 2) \implies y - 1 = 3x - 6 \implies y = 3x - 5$$
* 總結：一次函數的切線就是它本身，因此切線斜率恆等於國中學過的直線斜率 $m = 3$。

#### 習題 1.2 解答
**題目**：依照微積分求切線標準五步法，求二次多項式 $f(x) = x^2 + 2x$ 在點 $(1, 3)$ 處的導函數值與切線斜率，並寫出該點的切線方程式。

**詳細推演步驟（微積分求切線標準五步法）**：
* 第一步【確認目標與切點】：
  已知母函數為 $f(x) = x^2 + 2x$。目標切點為 $(x_0, y_0) = (1, 3)$。
* 第二步【列出導函數定義式】：
  $$f'(x) = \lim_{\Delta x \to 0} \frac{f(x + \Delta x) - f(x)}{\Delta x}$$
* 第三步【代入展開約分求導函數】：
  代入函數表達式：
  $$f'(x) = \lim_{\Delta x \to 0} \frac{[(x + \Delta x)^2 + 2(x + \Delta x)] - (x^2 + 2x)}{\Delta x}$$
  展開分子並合併同類項：
  $$[(x^2 + 2x\Delta x + (\Delta x)^2) + (2x + 2\Delta x)] - (x^2 + 2x) = 2x\Delta x + (\Delta x)^2 + 2\Delta x = (2x + 2)\Delta x + (\Delta x)^2$$
  因為 $\Delta x \neq 0$，約分消去分母 $\Delta x$：
  $$\frac{(2x + 2)\Delta x + (\Delta x)^2}{\Delta x} = 2x + 2 + \Delta x$$
  施加極限運算（$\Delta x \to 0$）：
  $$f'(x) = \lim_{\Delta x \to 0} (2x + 2 + \Delta x) = 2x + 2$$
* 第四步【計算目標點切線斜率】：
  將切點橫坐標 $x_0 = 1$ 代入導函數中：
  $$m = f'(1) = 2(1) + 2 = 4$$
* 第五步【點斜式寫出切線方程式】：
  通過點 $(1, 3)$ 且斜率為 $4$ 的切線方程式為：
  $$y - 3 = 4(x - 1) \implies y = 4x - 1$$

#### 習題 1.3 解答
**題目**：已知二次函數 $f(x) = -x^2 + 4$。求出在點 $(1, 3)$ 處的切線方程式。請分別代入 $x = 0.9$ 與 $x = 1.1$ 兩點，檢驗切線高度是否在兩側皆高於拋物線高度。

**詳細推演步驟（微積分求切線標準五步法）**：
* 第一步【確認目標與切點】：
  已知母函數為 $f(x) = -x^2 + 4$，切點坐標為 $(x_0, y_0) = (1, 3)$。
* 第二步【列出導函數定義式】：
  $$f'(x) = \lim_{\Delta x \to 0} \frac{f(x + \Delta x) - f(x)}{\Delta x}$$
* 第三步【代入展開約分求導函數】：
  $$f'(x) = \lim_{\Delta x \to 0} \frac{[-(x + \Delta x)^2 + 4] - (-x^2 + 4)}{\Delta x} = \lim_{\Delta x \to 0} \frac{-x^2 - 2x\Delta x - (\Delta x)^2 + 4 + x^2 - 4}{\Delta x}$$
  $$= \lim_{\Delta x \to 0} \frac{-2x\Delta x - (\Delta x)^2}{\Delta x} = \lim_{\Delta x \to 0} (-2x - \Delta x) = -2x$$
* 第四步【計算目標點切線斜率】：
  代入 $x_0 = 1$：
  $$m = f'(1) = -2(1) = -2$$
* 第五步【點斜式寫出切線方程式】：
  $$y - 3 = -2(x - 1) \implies y - 3 = -2x + 2 \implies y = -2x + 5$$
* 【幾何檢驗】：
  1. 在切點左側 $x = 0.9$ 處：
     拋物線高度：$y_{\text{curve}} = -(0.9)^2 + 4 = -0.81 + 4 = 3.19$。
     切線高度：$y_{\text{line}} = -2(0.9) + 5 = -1.8 + 5 = 3.20$。
     切線高於拋物線（$3.20 > 3.19$）。
  2. 在切點右側 $x = 1.1$ 處：
     拋物線高度：$y_{\text{curve}} = -(1.1)^2 + 4 = -1.21 + 4 = 2.79$。
     切線高度：$y_{\text{line}} = -2(1.1) + 5 = -2.2 + 5 = 2.80$。
     切線依然高於拋物線（$2.80 > 2.79$）。
  3. 全域代數驗證：
     $$y_{\text{line}} - f(x) = (-2x + 5) - (-x^2 + 4) = x^2 - 2x + 1 = (x - 1)^2 \ge 0$$
     對於開口向下的拋物線，切線在全域各處均高於或等於曲線，從上方籠罩拋物線。

#### 習題 1.4 解答
**題目**：已知二次函數 $f(x) = 2x^2 - 3x$。依照極限定義式推導其導函數 $f'(x)$，並計算在 $x = 2$ 處的切線斜率數值。

**詳細推演步驟（微積分求切線標準五步法）**：
* 第一步【確認目標與切點】：
  母函數為 $f(x) = 2x^2 - 3x$。在 $x_0 = 2$ 處，函數值為 $y_0 = f(2) = 2(2)^2 - 3(2) = 8 - 6 = 2$。切點為 $(2, 2)$。
* 第二步【列出導函數定義式】：
  $$f'(x) = \lim_{\Delta x \to 0} \frac{f(x + \Delta x) - f(x)}{\Delta x}$$
* 第三步【代入展開約分求導函數】：
  代入函數表達式：
  $$f'(x) = \lim_{\Delta x \to 0} \frac{[2(x + \Delta x)^2 - 3(x + \Delta x)] - (2x^2 - 3x)}{\Delta x}$$
  展開分子並按 $\Delta x$ 次數合併整理：
  $$= \lim_{\Delta x \to 0} \frac{[2(x^2 + 2x\Delta x + (\Delta x)^2) - 3x - 3\Delta x] - 2x^2 + 3x}{\Delta x}$$
  $$= \lim_{\Delta x \to 0} \frac{2x^2 + 4x\Delta x + 2(\Delta x)^2 - 3x - 3\Delta x - 2x^2 + 3x}{\Delta x}$$
  $$= \lim_{\Delta x \to 0} \frac{(4x - 3)\Delta x + 2(\Delta x)^2}{\Delta x}$$
  因為 $\Delta x \neq 0$，提取公因式約分：
  $$= \lim_{\Delta x \to 0} (4x - 3 + 2\Delta x) = 4x - 3 + 0 = 4x - 3$$
  導函數為 $f'(x) = 4x - 3$。
* 第四步【計算目標點切線斜率】：
  將 $x_0 = 2$ 代入導函數中：
  $$m = f'(2) = 4(2) - 3 = 8 - 3 = 5$$
* 第五步【點斜式寫出切線方程式】：
  通過點 $(2, 2)$ 且斜率為 $5$ 的切線方程式為：
  $$y - 2 = 5(x - 2) \implies y = 5x - 8$$

### 物理運動應用

#### 習題 1.5 解答
**題目**：列車自靜止啟動沿直線行駛，其位置函數為 $s(t) = 0.5t^2$（距離單位為公尺，時間單位為秒）。求列車在第 4 秒末那一瞬間的瞬時速度。

**詳細推演步驟**：
* 第一步：計算位置淨增量：
  $$\Delta s = s(4 + \Delta t) - s(4) = 0.5(4 + \Delta t)^2 - 0.5(4)^2 = 0.5(16 + 8\Delta t + (\Delta t)^2) - 8 = 4\Delta t + 0.5(\Delta t)^2 \text{ 公尺}$$
* 第二步：計算平均速度（$\Delta t \neq 0$）：
  $$\bar{v} = \frac{\Delta s}{\Delta t} = \frac{4\Delta t + 0.5(\Delta t)^2}{\Delta t} = 4 + 0.5\Delta t \text{ 公尺/秒}$$
* 第三步：施加極限求瞬時速度：
  $$v(4) = \lim_{\Delta t \to 0} (4 + 0.5\Delta t) = 4 \text{ 公尺/秒}$$
* 【量綱審查】：
  位移 $[\Delta s] = \text{m}$，時間間隔 $[\Delta t] = \text{s}$。
  平均速度量綱為 $[\bar{v}] = \frac{[\Delta s]}{[\Delta t]} = \text{m}\cdot\text{s}^{-1}$。
  常數 $0.5$ 來源於加速度的一半，量綱為 $\text{m}\cdot\text{s}^{-2}$；項 $0.5\Delta t$ 的量綱為 $(\text{m}\cdot\text{s}^{-2})\cdot\text{s} = \text{m}\cdot\text{s}^{-1}$。
  各項量綱齊次一致，最終速度單位為 $\text{m/s}$。

#### 習題 1.6 解答
**題目**：小球自地面垂直向上拋出，其高度函數為 $h(t) = 20t - 5t^2$（高度單位為公尺，時間單位為秒）。求小球在第 1 秒末的瞬時速度。
（提示：小球垂直向上拋出，當速度減慢至 $v(t) = 0$ 的瞬間，向上運動暫停並即將下墜，此時達到最高點。請先推導速度函數 $v(t)$，再令 $v(t) = 0$ 求解時間 $t$。）

**詳細推演步驟**：
* 第一步：求任意時刻 $t$ 的高度淨增量：
  $$\Delta h = h(t + \Delta t) - h(t) = [20(t + \Delta t) - 5(t + \Delta t)^2] - (20t - 5t^2)$$
  $$= 20t + 20\Delta t - 5t^2 - 10t\Delta t - 5(\Delta t)^2 - 20t + 5t^2 = (20 - 10t)\Delta t - 5(\Delta t)^2$$
* 第二步：計算差商平均速度（$\Delta t \neq 0$）：
  $$\frac{\Delta h}{\Delta t} = \frac{(20 - 10t)\Delta t - 5(\Delta t)^2}{\Delta t} = 20 - 10t - 5\Delta t$$
* 第三步：施加極限得出瞬時速度函數：
  $$v(t) = h'(t) = \lim_{\Delta t \to 0} (20 - 10t - 5\Delta t) = 20 - 10t \text{ (公尺/秒)}$$
* 第四步：計算第 1 秒末速度：
  代入 $t = 1$ 秒：
  $$v(1) = 20 - 10(1) = 10 \text{ 公尺/秒}$$
* 第五步：求解達到最高點的時刻：
  當小球達到最高點時，上升運動瞬間停止，瞬時速度為零：
  $$v(t) = 0 \implies 20 - 10t = 0 \implies 10t = 20 \implies t = 2 \text{ 秒}$$
  小球在第 2 秒末那一瞬間速度為零，達到運動最高點。
* 【量綱審查】：
  高度函數 $h(t) = 20t - 5t^2$ 中，常數 $20$ 為初速度，量綱為 $[20] = \text{m}\cdot\text{s}^{-1}$；常數 $5$ 為 $\frac{1}{2}g$，量綱為 $[5] = \text{m}\cdot\text{s}^{-2}$。
  速度函數 $v(t) = 20 - 10t$ 中，常數項為 $\text{m/s}$，項 $10t$ 的量綱為 $(\text{m}\cdot\text{s}^{-2})\cdot\text{s} = \text{m/s}$。
  等式各項量綱嚴格守恆。

#### 習題 1.7 解答
**題目**：向水槽注水時，水槽內的蓄水量函數為 $V(t) = 3t^2 + 2t$（容量單位為公升，時間單位為分鐘）。求在第 2 分鐘那一瞬間的瞬時注水速率（公升/分）。

**詳細推演步驟**：
* 第一步：瞬時注水速率即為蓄水量函數的導函數 $V'(t)$。
* 第二步：計算蓄水量淨增量：
  $$\Delta V = V(t + \Delta t) - V(t) = [3(t + \Delta t)^2 + 2(t + \Delta t)] - (3t^2 + 2t)$$
  $$= 3t^2 + 6t\Delta t + 3(\Delta t)^2 + 2t + 2\Delta t - 3t^2 - 2t = (6t + 2)\Delta t + 3(\Delta t)^2$$
* 第三步：計算差商（$\Delta t \neq 0$）：
  $$\frac{\Delta V}{\Delta t} = \frac{(6t + 2)\Delta t + 3(\Delta t)^2}{\Delta t} = 6t + 2 + 3\Delta t$$
* 第四步：施加極限求出導函數：
  $$V'(t) = \lim_{\Delta t \to 0} (6t + 2 + 3\Delta t) = 6t + 2 \text{ (公升/分)}$$
* 第五步：計算第 2 分鐘時的瞬時速率：
  代入 $t = 2$ 分鐘：
  $$V'(2) = 6(2) + 2 = 12 + 2 = 14 \text{ 公升/分}$$
* 【量綱審查】：
  蓄水量單位為公升（$\text{L}$），時間單位為分鐘（$\text{min}$）。
  差商 $\frac{\Delta V}{\Delta t}$ 的量綱為 $\text{L}\cdot\text{min}^{-1}$。
  極限運算不改變物理量綱，求得的瞬時注水速率單位為公升/分（$\text{L/min}$），與實際物理情境完全吻合。

### 局部線性估算

#### 習題 1.8 解答
**題目**：已知函數 $f(x) = x^2$ 的導數為 $2x$。選取基準點 $x_0 = 10$，利用局部線性逼近公式手算估計 $(10.02)^2$ 的數值，並與乘法展開的真實值比較誤差。

**詳細推演步驟**：
* 第一步：確定基準點與增量。
  選取基準點 $x_0 = 10$，基準函數值為 $f(10) = 10^2 = 100$。
  自變量增量為 $\Delta x = 10.02 - 10 = 0.02$。
* 第二步：計算基準點處的切線斜率：
  $$f'(10) = 2(10) = 20$$
* 第三步：代入局部線性逼近公式：
  $$f(10 + 0.02) \approx f(10) + f'(10)\Delta x = 100 + 20 \times 0.02 = 100 + 0.4 = 100.4$$
* 第四步：真實值與誤差分析：
  計算真實值：
  $$(10.02)^2 = (10 + 0.02)^2 = 100 + 2(10)(0.02) + (0.02)^2 = 100 + 0.4 + 0.0004 = 100.4004$$
  被線性逼近忽略的真實誤差為：
  $$100.4004 - 100.4 = 0.0004 = (\Delta x)^2$$
  由於 $\lim_{\Delta x \to 0} \frac{(\Delta x)^2}{\Delta x} = 0$，該項為標準的高階微小量 $o(\Delta x)$。手算一階估計值 $100.4$ 的相對誤差小於百萬分之四。

#### 習題 1.9 解答
**題目**：仿照例題 3 的方法，已知平方根函數的導數為 $f'(x) = \frac{1}{2\sqrt{x}}$。選取基準點 $x_0 = 100$，利用局部線性逼近公式手算估計 $\sqrt{104}$ 的近似數值，並透過平方逆運算檢驗其估算精度。

**詳細推演步驟**：
* 第一步：確定基準點與增量。
  在 $104$ 附近選取最容易開方的完全平方數作為基準點 $x_0 = 100$。
  基準函數值為 $f(100) = \sqrt{100} = 10$。
  自變量增量為 $\Delta x = 104 - 100 = 4$。
* 第二步：計算基準點處的切線斜率：
  $$f'(100) = \frac{1}{2\sqrt{100}} = \frac{1}{20} = 0.05$$
* 第三步：代入局部線性逼近公式：
  $$\sqrt{104} \approx f(100) + f'(100)\Delta x = 10 + 0.05 \times 4 = 10 + 0.2 = 10.2$$
* 第四步：平方逆運算精度檢驗與真實數值對比：
  1. 將手算估算值 $10.2$ 進行平方：
     $$(10.2)^2 = 104.04$$
     平方反向殘差為 $104.04 - 104 = 0.04$。
  2. 根據微分關係 $\Delta(y^2) \approx 2y\,\Delta y \approx 20\,\Delta y$，開方誤差約為平方殘差除以 20：
     $$|\Delta y| \approx \frac{0.04}{20} = 0.002$$
  3. 事實上，真實無理數為 $\sqrt{104} \approx 10.198039$。
     真實誤差為 $|10.2 - 10.198039| \approx 0.001961 \approx 0.0020$，相對誤差僅約萬分之二，檢驗完全吻合。

### 觀念通透挑戰

#### 習題 1.10 解答
**題目**：在推導二次函數導數時，我們得到算式 $\frac{2x\Delta x + (\Delta x)^2}{\Delta x} = 2x + \Delta x$：
1. 在分子與分母同時約去 $\Delta x$ 的那一步，我們必須依據什麼代數前提才能進行約分？為什麼此時 $\Delta x$ 絕不能等於 0？
2. 在約分得到 $2x + \Delta x$ 之後，極限算子 $\lim_{\Delta x \to 0}$ 是如何決定出最終結果 $2x$ 的？此時分母是否還存在為零的危險？

**詳細解答**：
1. **第一問解答（約分的代數前提）**：
   * 必須依據的前提是「自變量增量非零的前提：$\Delta x \neq 0$」。
   * 原因：根據算術公理，除數絕對不能為零。若在約分前 $\Delta x = 0$，則分式分子與分母同時為零，變成未定式 $\frac{0}{0}$，代數除法在此刻完全崩潰。只有嚴格保證 $\Delta x \neq 0$，我們才能合法地在分子與分母同除以 $\Delta x$，將公因式安全消除。
2. **第二問解答（極限算子的作用）**：
   * 約分完成後，式子化簡為連續的一階多項式 $2x + \Delta x$。此時分母已經完全沒有 $\Delta x$，分母為零的危機已經被代數手續徹底解除。
   * 極限算子 $\lim_{\Delta x \to 0}$ 不是強行把零塞入分母，而是考察函數隨 $\Delta x$ 縮小至零時的趨勢。根據極限運算法則，常數項 $2x$ 保持不變，線性項 $\Delta x$ 的極限精確為 $0$。整式數值連續收斂於 $2x + 0 = 2x$。
