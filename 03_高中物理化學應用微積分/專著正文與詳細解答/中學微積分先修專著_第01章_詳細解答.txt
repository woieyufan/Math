# 中學微積分先修專著·第一章 詳細解答手冊

## 一、公理建構示範例題詳細解答

### 例題 1 解答

#### 題幹核心目標
依據導數的第一性原理公理定義，推導二次函數 $f(x) = x^2$ 的導函數 $f'(x)$。
完整展現割線斜率化簡、非零約分合法性判定與極限算子作用過程，並進行量綱齊次性審查。

#### 嚴密推演步驟
第一步，寫出導數的公理極限定義式。
根據導數定義，函數在任意點 $x$ 處的導數為：
$$f'(x) = \lim_{\Delta x \to 0} \frac{f(x + \Delta x) - f(x)}{\Delta x}$$

第二步，計算分子中的函數淨增量。
將函數解析式 $f(x) = x^2$ 代入分子：
$$f(x + \Delta x) - f(x) = (x + \Delta x)^2 - x^2$$
應用完全平方公式展開：
$$(x + \Delta x)^2 - x^2 = x^2 + 2x\Delta x + (\Delta x)^2 - x^2 = 2x\Delta x + (\Delta x)^2$$

第三步，構造割線斜率代數商並進行合法約分。
割線斜率的代數表達式為：
$$m_{\text{sec}} = \frac{2x\Delta x + (\Delta x)^2}{\Delta x}$$
在自變量趨向於零的動態收縮過程中，增量始終滿足非零戒律 $\Delta x \neq 0$。
因為除數不為零，我們可以依法提取分子公因式並與分母進行約分：
$$\frac{\Delta x (2x + \Delta x)}{\Delta x} = 2x + \Delta x$$
此時代數商已經化簡為平滑的一階多項式，原先隱含的零除以零危機完全解除。

第四步，施加極限算子得出封閉式。
對化簡後的代數式施加極限算子：
$$f'(x) = \lim_{\Delta x \to 0} (2x + \Delta x) = 2x + 0 = 2x$$

第五步，量綱齊次性審查與幾何切線驗證。
若自變量 $x$ 具有長度量綱 $[x] = \mathrm{L}$，則函數 $f(x) = x^2$ 具有面積量綱 $[f(x)] = \mathrm{L}^2$。
依據導數定義，微商算子的量綱為：
$$\left[\frac{\mathrm{d}f}{\mathrm{d}x}\right] = \frac{[f(x)]}{[x]} = \frac{\mathrm{L}^2}{\mathrm{L}} = \mathrm{L}$$
求得的導函數為 $2x$，其量綱為 $[2x] = \mathrm{L}$。
等式兩側量綱嚴格守恆。
在幾何上，此結果表明在任意點 $x$，拋物線切線的傾斜斜率恆等於該點橫坐標的兩倍。

### 例題 2 解答

#### 題幹核心目標
針對自由落體運動位移函數 $s(t) = 4.9t^2$（米，秒），計算 $t = 2$ 秒時的瞬時速度。
展示平均速度差商構造、殘差項無窮小階數分析，以及極限下瞬時速度的精準確定。

#### 嚴密推演步驟
第一步，計算基準時刻與增量時刻的位移數值。
在基準時刻 $t_0 = 2$ 秒時，物體的位移為：
$$s(2) = 4.9 \times (2)^2 = 4.9 \times 4 = 19.6 \text{ 米}$$
在時間前進微小間隔 $\Delta t$ 之後，時刻為 $t = 2 + \Delta t$，物體的位移為：
$$s(2 + \Delta t) = 4.9(2 + \Delta t)^2 = 4.9\left(4 + 4\Delta t + (\Delta t)^2\right) = 19.6 + 19.6\Delta t + 4.9(\Delta t)^2 \text{ 米}$$

第二步，構造位移淨增量。
位移在時間間隔內的淨改變量為：
$$\Delta s = s(2 + \Delta t) - s(2) = \left[19.6 + 19.6\Delta t + 4.9(\Delta t)^2\right] - 19.6 = 19.6\Delta t + 4.9(\Delta t)^2 \text{ 米}$$

第三步，計算平均速度並分離主部與殘差項。
在時間增量滿足非零前提 $\Delta t \neq 0$ 下，平均速度等於位移增量除以時間增量：
$$\bar{v} = \frac{\Delta s}{\Delta t} = \frac{19.6\Delta t + 4.9(\Delta t)^2}{\Delta t} = 19.6 + 4.9\Delta t$$
表達式由兩部分組成。
第一部分是恆定數值 $19.6$，不隨時間間隔改變。
第二部分是動態殘差項 $4.9\Delta t$。

第四步，無窮小階數判定與極限瞬時速度求解。
考察殘差項相對於時間增量的一階比值極限：
$$\lim_{\Delta t \to 0} \frac{4.9(\Delta t)^2}{\Delta t} = \lim_{\Delta t \to 0} 4.9\Delta t = 0$$
這證明殘差項相對於位移主部是更高階的微小量。
當時間間隔縮小為零時，殘差項平滑消融。
瞬時速度取極限為：
$$v(2) = \lim_{\Delta t \to 0} \bar{v} = \lim_{\Delta t \to 0} (19.6 + 4.9\Delta t) = 19.6 \text{ 米/秒}$$

第五步，物理量綱檢驗。
常數 $4.9$ 的物理來源是 $\frac{1}{2}g$，其量綱為加速度 $[4.9] = \mathrm{L}\cdot \mathrm{T}^{-2}$。
增量 $\Delta t$ 的量綱為時間 $[\Delta t] = \mathrm{T}$。
乘積項 $4.9\Delta t$ 的量綱為：
$$[4.9\Delta t] = (\mathrm{L}\cdot \mathrm{T}^{-2}) \cdot \mathrm{T} = \mathrm{L}\cdot \mathrm{T}^{-1} \text{ (米/秒)}$$
所有相加項與最終速度的量綱完全一致。

### 例題 3 解答

#### 題幹核心目標
在不使用計算機的情況下，利用局部仿射線性逼近公式手算估計 $\sqrt{101}$ 的近似值。
選取最優基準點，並使用二階小量對誤差界限進行定量分析與幾何驗證。

#### 嚴密推演步驟
第一步，構造研究函數並選取最優基準點。
設定目標函數為平方根函數 $f(x) = \sqrt{x} = x^{1/2}$。
求值目標點為 $x = 101$。
我們在目標點附近選取完全平方數作為基準點 $x_0 = 100$。
自變量的增量為：
$$\Delta x = 101 - 100 = 1$$

第二步，計算基準點的函數值與一階導數值。
基準點的函數值為整數：
$$f(100) = \sqrt{100} = 10$$
平方根函數的一階導函數解析式為：
$$f'(x) = \frac{1}{2\sqrt{x}} = \frac{1}{2}x^{-1/2}$$
將基準點 $x_0 = 100$ 代入導函數中：
$$f'(100) = \frac{1}{2\sqrt{100}} = \frac{1}{20} = 0.05$$

第三步，應用局部仿射線性逼近開展手算。
局部仿射線性逼近的一階展開式為：
$$f(x_0 + \Delta x) \approx f(x_0) + f'(x_0)\Delta x$$
將求得的基準數值代入展開式：
$$\sqrt{101} \approx 10 + 0.05 \times 1 = 10.05$$

第四步，二階小量分析與誤差定性估計。
為了評估線性逼近的截斷誤差，我們求出函數的二階導數：
$$f''(x) = \frac{\mathrm{d}}{\mathrm{d}x}\left(\frac{1}{2}x^{-1/2}\right) = -\frac{1}{4}x^{-3/2} = -\frac{1}{4(\sqrt{x})^3}$$
在基準點 $x_0 = 100$ 處：
$$f''(100) = -\frac{1}{4 \times (10)^3} = -\frac{1}{4000} = -0.00025$$
依據二階泰勒展開，誤差修正項的主部為：
$$R_1 = \frac{1}{2}f''(100)(\Delta x)^2 = \frac{1}{2}(-0.00025)(1)^2 = -0.000125$$
負號表明切線線性逼近值略高於真實函數值。
經過二階微調後的數值為：
$$\sqrt{101} \approx 10.05 - 0.000125 = 10.049875$$

第五步，代數平方驗證與上凸幾何形狀反思。
我們直接將一階估算值 $10.05$ 平方：
$$(10.05)^2 = 101.0025$$
平方值與真實值 $101$ 之間的絕對差距僅有 $0.0025$。
這說明一階估算的相對誤差小於萬分之零點二五。
從幾何角度看，平方根曲線是嚴格向上凸起的弧線，二階導數處處為負。
切線作為支撐超平面始終位於曲線上方，因此一次仿射逼近必然給出真實數值的嚴格上限。

## 二、課後挑戰習題詳細解答

### 第一階：基礎公理與純數運算

#### 習題 1 解答

#### 題幹核心目標
閉卷默寫單變量函數導數公理極限定義式，註明非零前提與算子運作順序。

#### 嚴密推演步驟
第一步，標準公理定義式書寫。
設函數 $f$ 在點 $x_0$ 的某開鄰域內有定義。
導數 $f'(x_0)$ 定義為割線斜率在自變量增量趨於零時的極限：
$$f'(x_0) = \left. \frac{\mathrm{d}f}{\mathrm{d}x} \right|_{x=x_0} = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}$$

第二步，非零前提的代數約束。
在差商分式中，分母增量必須嚴格標註條件 $\Delta x \neq 0$。
此條件保證在運算的第一階段，表達式處於初等代數的合法運算域內。
任何分母為零的表達式在代數系統中均為未定義。

第三步，極限算子的介入時機與操作本質。
求導過程包含嚴格的時間先後次序。
操作第一階段是純粹的函數差值構造與因式化簡。
此階段依靠代數恆等變形消去分母中的 $\Delta x$ 因子。
操作第二階段才是極限算子 $\lim_{\Delta x \to 0}$ 的啟動。
極限算子考察的是整體表達式在 $\Delta x$ 無限逼近零時的穩定收斂數值。
若過早引入極限，將直接導致零除以零未定式。
若不引入極限，表達式將始終停留在依賴於 $\Delta x$ 的割線狀態。

#### 習題 2 解答

#### 題幹核心目標
利用導數極限定義式，無跳步計算多項式 $f(x) = 3x^2 - 5x + 2$ 在 $x = 1$ 處的導數值。

#### 嚴密推演步驟
第一步，計算基準點處的函數值。
將 $x_0 = 1$ 代入多項式：
$$f(1) = 3(1)^2 - 5(1) + 2 = 3 - 5 + 2 = 0$$

第二步，計算擾動點處的函數值並展開。
將自變量代換為 $1 + \Delta x$：
$$f(1 + \Delta x) = 3(1 + \Delta x)^2 - 5(1 + \Delta x) + 2$$
利用二項式完全平方展開：
$$3\left(1 + 2\Delta x + (\Delta x)^2\right) - 5 - 5\Delta x + 2 = 3 + 6\Delta x + 3(\Delta x)^2 - 5 - 5\Delta x + 2$$
合併同類項：
$$f(1 + \Delta x) = (3 - 5 + 2) + (6 - 5)\Delta x + 3(\Delta x)^2 = 0 + \Delta x + 3(\Delta x)^2 = \Delta x + 3(\Delta x)^2$$

第三步，構造割線差商並在 $\Delta x \neq 0$ 條件下化簡。
割線差商為：
$$\frac{f(1 + \Delta x) - f(1)}{\Delta x} = \frac{\Delta x + 3(\Delta x)^2 - 0}{\Delta x} = \frac{\Delta x(1 + 3\Delta x)}{\Delta x}$$
因為 $\Delta x \neq 0$，約去分子與分母中的公因式 $\Delta x$：
$$\frac{f(1 + \Delta x) - f(1)}{\Delta x} = 1 + 3\Delta x$$

第四步，對化簡式施加極限算子。
令增量 $\Delta x$ 趨近於零：
$$f'(1) = \lim_{\Delta x \to 0} (1 + 3\Delta x) = 1 + 3(0) = 1$$
計算完成，函數在 $x=1$ 處的瞬時變化率精確等於 $1$。

#### 習題 3 解答

#### 題幹核心目標
判定微小量 $\alpha(\Delta x) = (\Delta x)^2 + 3\Delta x$ 相對於基準量 $\Delta x$ 的無窮小階數。

#### 嚴密推演步驟
第一步，寫出無窮小量階數比較判定商。
為了比較 $\alpha(\Delta x)$ 與基準無窮小量 $\Delta x$ 的收斂速率，我們建立二者之比的極限式：
$$L = \lim_{\Delta x \to 0} \frac{\alpha(\Delta x)}{\Delta x}$$

第二步，代入表達式並化簡分式。
將多項式代入比值：
$$\frac{\alpha(\Delta x)}{\Delta x} = \frac{(\Delta x)^2 + 3\Delta x}{\Delta x}$$
在 $\Delta x \neq 0$ 的條件下提取公因式約分：
$$\frac{\Delta x(\Delta x + 3)}{\Delta x} = \Delta x + 3$$

第三步，計算極限並依據公理判定階數。
計算極限值：
$$L = \lim_{\Delta x \to 0} (\Delta x + 3) = 0 + 3 = 3$$
極限值為一個不等於零的有限常數 $3 \neq 0$。
依據無窮小量階數的公理標準：
當比值極限為非零常數時，兩者互為同階無窮小量。
因此 $\alpha(\Delta x)$ 與基準增量 $\Delta x$ 是同階無窮小量。
其中線性項 $3\Delta x$ 是其主部，二次項 $(\Delta x)^2$ 則是更高階的伴隨殘差。

#### 習題 4 解答

#### 題幹核心目標
利用一階局部仿射線性逼近手算估計 $(1.003)^{10}$，並給出殘差無窮小階數。

#### 嚴密推演步驟
第一步，建立函數模型與基準點。
設定目標函數為冪函數 $f(x) = x^{10}$。
求值目標點為 $x = 1.003$。
我們選取整數點作為基準點 $x_0 = 1$。
自變量的微小增量為 $\Delta x = 1.003 - 1 = 0.003$。

第二步，計算基準點處的函數值與一階導函數值。
基準點的函數值為：
$$f(1) = 1^{10} = 1$$
對冪函數求導，一階導函數為：
$$f'(x) = 10x^9$$
將基準點代入導函數：
$$f'(1) = 10 \times (1)^9 = 10$$

第三步，代入仿射逼近公式計算一階近似值。
仿射逼近公式為：
$$f(x_0 + \Delta x) \approx f(x_0) + f'(x_0)\Delta x$$
代入已知數值：
$$(1.003)^{10} \approx 1 + 10 \times 0.003 = 1 + 0.03 = 1.03$$

第四步，二項式定理展開與殘差階數判定。
依據牛頓二項式定理，真值的完整展開式為：
$$(1 + 0.003)^{10} = 1 + \binom{10}{1}(0.003) + \binom{10}{2}(0.003)^2 + \sum_{k=3}^{10} \binom{10}{k}(0.003)^k$$
一階逼近截斷之後的殘差項為：
$$R_1 = \binom{10}{2}(0.003)^2 + \dots = 45 \times 0.000009 + \dots = 0.000405 + \dots$$
計算殘差相對於增量的一階比值極限：
$$\lim_{\Delta x \to 0} \frac{R_1}{\Delta x} = \lim_{\Delta x \to 0} \frac{45(\Delta x)^2 + O((\Delta x)^3)}{\Delta x} = \lim_{\Delta x \to 0} [45\Delta x + O((\Delta x)^2)] = 0$$
這證明殘差項為高階無窮小量 $o(\Delta x)$。
其領頭殘差為二階無窮小量，量級為 $(\Delta x)^2$。
真值約為 $1.030405$，線性逼近 $1.03$ 的誤差僅約為萬分之四。

### 第二階：自然科學跨學科實戰

#### 習題 5 解答

#### 題幹核心目標
針對質點運動方程 $x(t) = t^3 - 6t^2 + 9t$，利用極限定義求解瞬時速度，求速度零點並剖析折返點物理意涵。

#### 嚴密推演步驟
第一步，利用導數定義推導瞬時速度函數。
位移增量為：
$$\Delta x = x(t + \Delta t) - x(t) = (t + \Delta t)^3 - 6(t + \Delta t)^2 + 9(t + \Delta t) - (t^3 - 6t^2 + 9t)$$
展開三次項與二次項：
$$(t + \Delta t)^3 = t^3 + 3t^2\Delta t + 3t(\Delta t)^2 + (\Delta t)^3$$
$$-6(t + \Delta t)^2 = -6t^2 - 12t\Delta t - 6(\Delta t)^2$$
$$9(t + \Delta t) = 9t + 9\Delta t$$
相加並減去 $x(t)$ 後，位移增量化簡為：
$$\Delta x = (3t^2 - 12t + 9)\Delta t + (3t - 6)(\Delta t)^2 + (\Delta t)^3$$
在 $\Delta t \neq 0$ 條件下計算平均速度：
$$\frac{\Delta x}{\Delta t} = (3t^2 - 12t + 9) + (3t - 6)\Delta t + (\Delta t)^2$$
令時間增量趨近於零，高階項全部消失：
$$v(t) = \lim_{\Delta t \to 0} \frac{\Delta x}{\Delta t} = 3t^2 - 12t + 9 \text{ 米/秒}$$

第二步，求解速度為零的時間點。
令瞬時速度等於零：
$$3t^2 - 12t + 9 = 0$$
兩端同除以 $3$ 並因式分解：
$$t^2 - 4t + 3 = 0 \implies (t - 1)(t - 3) = 0$$
解得質點速度為零的兩個時間點為：
$$t_1 = 1 \text{ 秒}, \quad t_2 = 3 \text{ 秒}$$

第三步，折返點的物理運動學分析。
我們分析三個時間區間的速度正負號與質點運動方向。
在區間 $0 \le t < 1$ 內，因式 $(t-1) < 0$ 且 $(t-3) < 0$，乘積為正，速度 $v(t) > 0$。
質點沿坐標正方向向前運動。
在 $t = 1$ 秒瞬間，質點到達位置 $x(1) = 1 - 6 + 9 = 4$ 米。
速度短暫減速至零，質點在此處停止前進並調轉運動方向。
在區間 $1 < t < 3$ 內，因式 $(t-1) > 0$ 且 $(t-3) < 0$，乘積為負，速度 $v(t) < 0$。
質點掉頭向原點方向反向倒退運動。
在 $t = 3$ 秒瞬間，質點退回位置 $x(3) = 27 - 54 + 27 = 0$ 米。
速度再度降為零，質點結束倒退。
在區間 $t > 3$ 之後，因式均為正，速度 $v(t) > 0$，質點再度恢復正向加速前進。
因此 $t = 1$ 秒與 $t = 3$ 秒是質點空間運動軌跡的兩處物理折返點。

第四步，量綱齊次性檢查。
函數各項係數隱含著適應時間冪次的物理量綱。
一次項係數 $9$ 的量綱為速度 $[9] = \mathrm{L}\cdot \mathrm{T}^{-1}$。
二次項係數 $12$ 的量綱為加速度 $[12] = \mathrm{L}\cdot \mathrm{T}^{-2}$。
三次項係數 $3$ 的量綱為加速度變化率 $[3] = \mathrm{L}\cdot \mathrm{T}^{-3}$。
微商表達式各項量綱均為 $\mathrm{L}\cdot \mathrm{T}^{-1}$，物理量綱自洽。

#### 習題 6 解答

#### 題幹核心目標
針對平面點光源 $(0, h)$ 與動態接收點 $(x, 0)$，推導光程變化率極限，剖析三角幾何投影。

#### 嚴密推演步驟
第一步，建立光程幾何函數。
依據勾股定理，點光源 $(0, h)$ 到探測器位置 $(x, 0)$ 的空間光程距離為：
$$L(x) = \sqrt{x^2 + h^2}$$

第二步，計算位移增量對應的光程差。
當探測器平移至 $x + \Delta x$ 時，新的光程為：
$$L(x + \Delta x) = \sqrt{(x + \Delta x)^2 + h^2}$$
光程淨增量為：
$$\Delta L = \sqrt{(x + \Delta x)^2 + h^2} - \sqrt{x^2 + h^2}$$

第三步，分子有理化與代數化簡。
將分子乘以其共軛根式進行有理化：
$$\Delta L = \frac{\left[(x + \Delta x)^2 + h^2\right] - (x^2 + h^2)}{\sqrt{(x + \Delta x)^2 + h^2} + \sqrt{x^2 + h^2}} = \frac{2x\Delta x + (\Delta x)^2}{\sqrt{(x + \Delta x)^2 + h^2} + \sqrt{x^2 + h^2}}$$
在 $\Delta x \neq 0$ 條件下計算割線比值：
$$\frac{\Delta L}{\Delta x} = \frac{2x + \Delta x}{\sqrt{(x + \Delta x)^2 + h^2} + \sqrt{x^2 + h^2}}$$

第四步，取極限得出瞬時變化率。
令 $\Delta x \to 0$，分子趨於 $2x$，分母趨於 $2\sqrt{x^2+h^2}$：
$$\frac{\mathrm{d}L}{\mathrm{d}x} = \lim_{\Delta x \to 0} \frac{\Delta L}{\Delta x} = \frac{2x}{2\sqrt{x^2 + h^2}} = \frac{x}{\sqrt{x^2 + h^2}}$$

第五步，幾何投影與三角物理意義剖析。
在光源、原點與探測器構成的直角三角形中：
斜邊長度為光線傳播路徑 $L = \sqrt{x^2 + h^2}$。
橫向鄰邊長度為探測器坐標 $x$。
若設光線與水平運動方向的夾角為 $\theta$，則比值為：
$$\cos\theta = \frac{x}{\sqrt{x^2 + h^2}}$$
這表明光程對橫向位移的瞬時變化率，恰好等於光線傳播方向在探測器運動方向上的投影餘弦值。
量綱審查方面，分子為長度，分母為長度，微商為無量綱量，與角度餘弦值的純數特性完全吻合。

#### 習題 7 解答

#### 題幹核心目標
推導材料熱膨脹經驗公式中線膨脹係數 $\alpha$ 的微商定義式，檢驗兩端物理量綱。

#### 嚴密推演步驟
第一步，由線性膨脹公式提取長度微商。
金屬棒受熱伸長經驗公式為：
$$L(T) = L_0(1 + \alpha \Delta T) = L_0 + L_0\alpha (T - T_0)$$
我們計算溫度由 $T$ 改變微小量 $\Delta T$ 時的長度變化：
$$L(T + \Delta T) - L(T) = \left[L_0 + L_0\alpha (T + \Delta T - T_0)\right] - \left[L_0 + L_0\alpha (T - T_0)\right] = L_0\alpha\Delta T$$
依據導數定義，長度對溫度的微商為：
$$\frac{\mathrm{d}L}{\mathrm{d}T} = \lim_{\Delta T \to 0} \frac{L(T + \Delta T) - L(T)}{\Delta T} = \lim_{\Delta T \to 0} \frac{L_0\alpha\Delta T}{\Delta T} = L_0\alpha$$

第二步，推導線膨脹係數的微商定義式。
將上式中的常數係數 $\alpha$ 獨立求解：
$$\alpha = \frac{1}{L_0} \frac{\mathrm{d}L}{\mathrm{d}T}$$
在更普遍的非線性熱力學環境下，瞬時線膨脹係數定義為單位長度的溫度微商：
$$\alpha(T) = \frac{1}{L(T)} \frac{\mathrm{d}L}{\mathrm{d}T}$$

第三步，國際單位制（SI）物理量綱齊次性證明。
我們逐項分析各物理量的基本量綱。
長度 $L$ 與初始長度 $L_0$ 的量綱為長度 $[L] = [L_0] = \mathrm{L}$。
溫度 $T$ 的量綱為熱力學溫度 $[T] = \Theta$（單位開爾文 $\mathrm{K}$ 或攝氏度 ${}^\circ\mathrm{C}$）。
長度對溫度的微商量綱為：
$$\left[\frac{\mathrm{d}L}{\mathrm{d}T}\right] = \frac{[L]}{[T]} = \mathrm{L}\cdot \Theta^{-1}$$
將量綱代入線膨脹係數定義式中：
$$[\alpha] = \left[\frac{1}{L_0}\right] \cdot \left[\frac{\mathrm{d}L}{\mathrm{d}T}\right] = \mathrm{L}^{-1} \cdot (\mathrm{L}\cdot \Theta^{-1}) = \Theta^{-1} = \mathrm{K}^{-1}$$
結果顯示線膨脹係數的量綱是溫度的倒數，表示每升高一度長度相對變化的分數比率，公式兩側量綱完美自洽。

#### 習題 8 解答

#### 題幹核心目標
推導托里拆利洩流水位 $h(t) = H(1 - t/T)^2$ 的瞬時下降速率，剖析負號物理意涵與邊界運動特徵。

#### 嚴密推演步驟
第一步，計算水位在時間增量內的代數變化。
水位函數為：
$$h(t) = H\left(1 - \frac{t}{T}\right)^2$$
當時間增加 $\Delta t$ 時：
$$h(t + \Delta t) = H\left(1 - \frac{t + \Delta t}{T}\right)^2 = H\left[\left(1 - \frac{t}{T}\right) - \frac{\Delta t}{T}\right]^2$$
利用二項展開式展開平方項：
$$h(t + \Delta t) = H\left[\left(1 - \frac{t}{T}\right)^2 - 2\left(1 - \frac{t}{T}\right)\frac{\Delta t}{T} + \frac{(\Delta t)^2}{T^2}\right]$$
計算水位淨增量：
$$\Delta h = h(t + \Delta t) - h(t) = H\left[-2\left(1 - \frac{t}{T}\right)\frac{\Delta t}{T} + \frac{(\Delta t)^2}{T^2}\right]$$

第二步，構造割線變化率並取極限。
在 $\Delta t \neq 0$ 條件下計算平均變化率：
$$\frac{\Delta h}{\Delta t} = -\frac{2H}{T}\left(1 - \frac{t}{T}\right) + \frac{H\Delta t}{T^2}$$
令時間增量趨近於零，高階小量消失：
$$\frac{\mathrm{d}h}{\mathrm{d}t} = \lim_{\Delta t \to 0} \frac{\Delta h}{\Delta t} = -\frac{2H}{T}\left(1 - \frac{t}{T}\right)$$

第三步，負號物理意涵與水流運動狀態解讀。
負號的出現源於位移的向量性。
因為水箱中的水持續流出，水位高度 $h(t)$ 隨時間單調遞減，增量 $\Delta h$ 恆為負值。
負號嚴謹地指明水位變化的速度方向指向坐標軸負方向（向下）。

第四步，初始時刻與排空時刻的特徵對比。
在剛開孔的初始瞬間 $t = 0$：
$$\left.\frac{\mathrm{d}h}{\mathrm{d}t}\right|_{t=0} = -\frac{2H}{T}$$
下降速率達到最大峰值。
物理上此時水箱處於滿水位狀態，底部小孔承受最大的靜水壓強 $\rho g H$，孔口流速最高。
在完全洩空的終止瞬間 $t = T$：
$$\left.\frac{\mathrm{d}h}{\mathrm{d}t}\right|_{t=T} = -\frac{2H}{T}(1 - 1) = 0$$
下降速率平滑衰減為零。
這表明水位並非以猛烈撞擊的突變方式見底，而是隨壓強降為零平穩地停滯。
量綱方面，$H$ 為米，$T$ 為秒，$\frac{2H}{T}$ 的量綱為米/秒，物理量綱自洽。

### 第三階：邊界奇異點與深水區挑戰

#### 習題 9 解答

#### 題幹核心目標
利用夾擠定理與導數定義，證明病態狄利克雷加權函數 $f(x) = x^2 D(x)$ 在原點可微並求 $f'(0)$。

#### 嚴密推演步驟
第一步，審查狄利克雷加權函數的點值。
狄利克雷函數 $D(x)$ 定義為：有理數點為 $1$，無理數點為 $0$。
在原點 $x = 0$ 處，因為 $0$ 是有理數，$D(0) = 1$。
函數在原點的精確值為：
$$f(0) = (0)^2 \times D(0) = 0 \times 1 = 0$$

第二步，構造原點處的割線斜率差商。
設自變量產生非零微小增量 $\Delta x \neq 0$。
原點處的割線斜率差商為：
$$\frac{f(0 + \Delta x) - f(0)}{\Delta x} = \frac{(\Delta x)^2 D(\Delta x) - 0}{\Delta x} = \frac{(\Delta x)^2 D(\Delta x)}{\Delta x}$$
因為 $\Delta x \neq 0$，約去分母公因式：
$$\frac{f(0 + \Delta x) - f(0)}{\Delta x} = \Delta x \cdot D(\Delta x)$$

第三步，建立夾擠不等式。
無論自變量 $\Delta x$ 取何值，$D(\Delta x)$ 的取值範圍嚴格受限於集合 $\{0, 1\}$。
因此函數值恆滿足不等式：
$$0 \le D(\Delta x) \le 1$$
對不等式全體乘以絕對值 $|\Delta x|$：
$$0 \le |\Delta x \cdot D(\Delta x)| \le |\Delta x|$$
將其展開為雙邊不等式：
$$-|\Delta x| \le \Delta x \cdot D(\Delta x) \le |\Delta x|$$

第四步，應用夾擠定理求導函數極限。
當自變量趨向於零時，考察兩側邊界函數的極限：
$$\lim_{\Delta x \to 0} (-|\Delta x|) = 0, \quad \lim_{\Delta x \to 0} |\Delta x| = 0$$
兩側邊界極限均存在且精確相等。
依據極限夾擠定理，中間割線差商的極限必然存在且等於公共邊界值：
$$f'(0) = \lim_{\Delta x \to 0} [\Delta x \cdot D(\Delta x)] = 0$$
證明完成。函數在原點完全可微，且其導數值為 $0$。

第五步，壓制病態振盪的深層幾何分析。
狄利克雷函數本身處處不連續，其跳躍振盪幅度始終為 $1$。
若僅乘以一階因子 $x$，差商將退化為 $D(\Delta x)$，在有理數與無理數之間持續於 $1$ 與 $0$ 跳躍，導致極限不存在。
然而乘以二次方因子 $x^2$ 時，函數整體被約束在兩條拋物線之間：
$$-x^2 \le 0 \le f(x) \le x^2$$
在原點鄰域，拋物線以二階收縮速率急劇收緊包絡。
這使得即便微觀振盪極其瘋狂，整體增量依然被壓制為高階小量。
割線斜率在原點被強行鎖定在水平切線方向。

#### 習題 10 解答

#### 題幹核心目標
證明高頻振盪函數 $f(x) = x \sin(1/x)$ 在原點連續但不可微，揭示階數平衡破裂機制。

#### 嚴密推演步驟
第一步，證明函數在原點處的連續性。
函數在原點的值給定為 $f(0) = 0$。
當 $x \neq 0$ 時，考慮差值大小：
$$|f(x) - f(0)| = |x \sin(1/x) - 0| = |x| \cdot |\sin(1/x)|$$
因為正弦函數的有界性，對於任意實數均有 $|\sin(1/x)| \le 1$。
因此滿足夾擠不等式：
$$0 \le |f(x) - f(0)| \le |x|$$
當 $x \to 0$ 時，右端極限為零：
$$\lim_{x \to 0} |x| = 0 \implies \lim_{x \to 0} f(x) = 0 = f(0)$$
極限值等於函數點值，因此函數在原點處嚴格連續。

第二步，構造原點處的割線斜率差商。
取增量 $\Delta x \neq 0$，寫出原點割線斜率表達式：
$$\frac{f(0 + \Delta x) - f(0)}{\Delta x} = \frac{\Delta x \sin(1/\Delta x) - 0}{\Delta x} = \frac{\Delta x \sin(1/\Delta x)}{\Delta x}$$
因為 $\Delta x \neq 0$，約去公因式得出：
$$\frac{f(0 + \Delta x) - f(0)}{\Delta x} = \sin\left(\frac{1}{\Delta x}\right)$$

第三步，選取特殊子序列證明極限發散。
我們考察當 $\Delta x \to 0$ 時 $\sin(1/\Delta x)$ 的性態。
選取趨於零的第一組正數數列：
$$\Delta x_n = \frac{1}{\frac{\pi}{2} + 2n\pi} \quad (n = 1, 2, 3, \dots)$$
當 $n \to \infty$ 時，$\Delta x_n \to 0$。
將此數列代入差商中：
$$\lim_{n \to \infty} \sin\left(\frac{1}{\Delta x_n}\right) = \lim_{n \to \infty} \sin\left(\frac{\pi}{2} + 2n\pi\right) = \lim_{n \to \infty} 1 = 1$$
選取趨於零的第二組正數數列：
$$\Delta x'_n = \frac{1}{-\frac{\pi}{2} + 2n\pi} \quad (n = 1, 2, 3, \dots)$$
當 $n \to \infty$ 時，$\Delta x'_n \to 0$。
代入差商中：
$$\lim_{n \to \infty} \sin\left(\frac{1}{\Delta x'_n}\right) = \lim_{n \to \infty} \sin\left(-\frac{\pi}{2} + 2n\pi\right) = \lim_{n \to \infty} (-1) = -1$$
選取趨於零的第三組正數數列：
$$\Delta x''_n = \frac{1}{n\pi} \quad (n = 1, 2, 3, \dots)$$
代入差商中：
$$\lim_{n \to \infty} \sin\left(\frac{1}{\Delta x''_n}\right) = \lim_{n \to \infty} \sin(n\pi) = 0$$
沿著不同的趨近路徑，割線斜率收斂到不同的數值。
依據極限的唯一性定理，極限 $\lim_{\Delta x \to 0} \sin(1/\Delta x)$ 不存在。
因此函數在原點處不可微。

第四步，階數斷層與振盪失守的深層幾何機制。
在此函數中，正弦振盪的振幅雖然被前面的 $x$ 壓制為零（使得函數維持連續）。
但是在計算割線斜率時，除以 $\Delta x$ 的操作恰好將一階阻尼因子徹底抵消。
差商喪失了阻尼保護，直接退化為純粹的未阻尼高頻振盪 $\sin(1/\Delta x)$。
在原點附近的極小空間內，函數圖像在直線 $y = x$ 與 $y = -x$ 之間無限次劇烈起伏。
割線像失控的指南針指針一樣在區間 $[-1, 1]$ 之間永無止境地瘋狂擺動。
它永遠無法鎖定在任何穩定的幾何切線方向上。
這展示了連續性與可微性之間的本質鴻溝：連續只需要數值貼合，而可微性要求幾何方向的平滑錨定。
