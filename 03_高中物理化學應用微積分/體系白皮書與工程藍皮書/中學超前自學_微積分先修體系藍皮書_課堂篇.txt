## 第二篇：Stage I：公理出發、無窮小與單項式微積分（Topics 1–3）

> **本階研討目標**：從離散代數到連續變化的認知躍遷，建立無窮小階數直覺與算子線性本質

### Topic 1：無窮小量階數與極限定義（代數非零與極限為零的本質破局）

> **🥋 道場研討核心（Dojo Core Mission）**：黑板直擊：在不使用柯西複雜不等式夾逼的前提下，利用代數非零約分演示極限過渡，戳破學生『直接把 $\Delta x=0$ 代入』的偽推導。

#### 黑板板書必演 7 條核心公式鏈
- **`Brd 1.1`【割線斜率之代數商定義式】**：$$m_{\text{sec}} = \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x} \quad (\Delta x \neq 0)$$
- **`Brd 1.2`【無窮小量階數比較判定式】**：$$\lim_{\Delta x \to 0} \frac{o((\Delta x)^k)}{(\Delta x)^k} = 0 \quad (k \in \mathbb{N}^+)$$
- **`Brd 1.3`【切線斜率的算子極限定義式】**：$$f'(x_0) = \left. \frac{\mathrm{d}f}{\mathrm{d}x} \right|_{x=x_0} = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}$$
- **`Brd 1.4`【局部仿射線性逼近展開式】**：$$f(x_0 + \Delta x) = f(x_0) + f'(x_0)\Delta x + o(\Delta x)$$
- **`Brd 1.5`【瞬時速度之極限微分定義式】**：$$v(t_0) = \lim_{\Delta t \to 0} \frac{x(t_0 + \Delta t) - x(t_0)}{\Delta t} = \frac{\mathrm{d}x}{\mathrm{d}t}$$
- **`Brd 1.6`【自由落體瞬時速度封閉解】**：$$x(t) = \frac{1}{2}gt^2 \implies v(t) = \lim_{\Delta t \to 0} \left(gt + \frac{1}{2}g\Delta t\right) = gt$$
- **`Brd 1.7`【無窮小階數失守發散檢驗式】**：$$\lim_{\Delta x \to 0} \frac{\sqrt{\Delta x}}{\Delta x} = \lim_{\Delta x \to 0} \frac{1}{\sqrt{\Delta x}} = \infty \quad (\text{低階無窮小無法形成有限導數})$$

### Topic 2：多項式冪法則與線性算子（代數降階與疊加原理）

> **🥋 道場研討核心（Dojo Core Mission）**：黑板直擊：拆解二項式展開的高階小量組合數，讓學生在黑板上親自完成從 $n \in \mathbb{N}$ 推廣到負整數與有理數冪的無跳步代數鏈條。

#### 黑板板書必演 7 條核心公式鏈
- **`Brd 2.1`【二項式定理展開式】**：$$(x + \Delta x)^n = x^n + n x^{n-1}\Delta x + \sum_{k=2}^n \binom{n}{k} x^{n-k} (\Delta x)^k$$
- **`Brd 2.2`【單項式冪微分核心法則】**：$$\frac{\mathrm{d}}{\mathrm{d}x}(x^n) = \lim_{\Delta x \to 0} \frac{n x^{n-1}\Delta x + O((\Delta x)^2)}{\Delta x} = n x^{n-1} \quad (n \in \mathbb{R})$$
- **`Brd 2.3`【微分算子線性疊加公理】**：$$\frac{\mathrm{d}}{\mathrm{d}x}\big(c_1 f(x) + c_2 g(x)\big) = c_1 \frac{\mathrm{d}f}{\mathrm{d}x} + c_2 \frac{\mathrm{d}g}{\mathrm{d}x}$$
- **`Brd 2.4`【高階代數降階算子式】**：$$\frac{\mathrm{d}^k}{\mathrm{d}x^k}(x^n) = n(n-1)\cdots(n-k+1) x^{n-k} \quad (k \le n)$$
- **`Brd 2.5`【多項式自由落體二次加速度微商式】**：$$a(t) = \frac{\mathrm{d}^2}{\mathrm{d}t^2}\left(\frac{1}{2}at^2 + v_0 t + x_0\right) = a \quad (\text{二階微商恆定})$$
- **`Brd 2.6`【負整數冪微分反比微商式】**：$$\frac{\mathrm{d}}{\mathrm{d}x}\left(\frac{1}{x^m}\right) = -m x^{-(m+1)} = -\frac{m}{x^{m+1}} \quad (m \in \mathbb{N}^+)$$
- **`Brd 2.7`【算子零核空間定理式】**：$$\frac{\mathrm{d}}{\mathrm{d}x} P(x) = 0 \iff P(x) \equiv C \quad (\text{常數函數為算子零核})$$

#### Topic 2 專屬 9 道道場攻防實彈題庫
##### 1. 黑板現場抽籤攻防題（Chalkboard Defense Tasks, 3 題）
- **`D1 2.1`**：學員甲上黑板推導 $(x^{-3})' = -3x^{-4}$，被導師打斷：『二項式定理只對正整數指數成立，你憑什麼把負數代入組合數 $\binom{-3}{k}$？給我用倒數極限定義補齊嚴密代數鏈！』
- **`D1 2.2`**：學員乙在黑板計算 $y = \sqrt{x}$ 的導數，導師質詢：『不准用公式，直接從割線極限與有理化展開，寫出為什麼有理數指數 $\frac{1}{2}$ 會跳到前面當係數。』
- **`D1 2.3`**：學員丙上黑板證明微分算子的線性性，導師詰問：『如果在求和極限中，項數不是有限項而是無窮項 $\sum_{k=1}^\infty u_k(x)$，微分算子還能逐項穿透嗎？舉出反例。』

##### 2. 未知自然科學情境破局題（Unseen Sandbox Scenarios, 3 題）
- **`D2 2.1`**：給定一個四維空間超球體體積公式 $V_4(R) = \frac{1}{2}\pi^2 R^4$，現場推導其表面積公式 $S_4(R) = \frac{\mathrm{d}V_4}{\mathrm{d}R}$，並給出幾何微元層次解釋。
- **`D2 2.2`**：某奇異介質中光速與深度呈冪律分佈 $v(y) = v_0 (y/h)^{1/3}$，現場構造折射率微商 $\frac{\mathrm{d}n}{\mathrm{d}y}$。

##### 3. 體制內聯考大題降維秒殺題（System Trivialization Arsenal, 3 題）

### Topic 3：切線代數本質與二重根定理（判別式之微積分超越）

> **🥋 道場研討核心（Dojo Core Mission）**：黑板直擊：在黑板上以高次多項式（三次、四次）實彈展示：聯立方程切線處必出現 $(x-x_0)^2$ 因子，摧毀高中生對二次判別式的路徑依賴。

#### 黑板板書必演 7 條核心公式鏈
- **`Brd 3.1`【切線標準點斜式方程】**：$$y - f(x_0) = f'(x_0)(x - x_0)$$
- **`Brd 3.2`【相交差函數代數構造式】**：$$D(x) = f(x) - \big[f(x_0) + f'(x_0)(x - x_0)\big]$$
- **`Brd 3.3`【二重根因子分解定理式】**：$$D(x_0) = 0 \quad \text{且} \quad D'(x_0) = 0 \iff D(x) = (x - x_0)^2 Q(x)$$
- **`Brd 3.4`【二次拋物線判別式與導數等價式】**：$$ax^2 + bx + c - (mx+k) = 0 \quad \text{有重根} \iff \Delta = 0 \iff m = 2ax_0 + b$$
- **`Brd 3.5`【法線斜率正交幾何條件式】**：$$m_{\text{normal}} = -\frac{1}{f'(x_0)} \quad (f'(x_0) \neq 0)$$
- **`Brd 3.6`【三次多項式拐點切線穿越方程】**：$$f(x) - L(x) = (x - x_0)^3 \iff f''(x_0) = 0 \quad (\text{三重根幾何穿透})$$
- **`Brd 3.7`【判別式局部退化失效檢驗式】**：$$f(x) = x^4 - 2x^2 \implies \text{公切線有兩條以上，單一二次判別式完全崩潰}$$

#### Topic 3 專屬 9 道道場攻防實彈題庫
##### 1. 黑板現場抽籤攻防題（Chalkboard Defense Tasks, 3 題）
- **`D1 3.1`**：學員甲上黑板求過點 $(0, -4)$ 到拋物線 $y=x^2$ 的切線，設切線斜率為 $m$ 後列出判別式 $\Delta = 0$。導師當場叫停：『把判別式擦掉！從切點 $(t, t^2)$ 出發寫出點斜式，演示未知數在切點的微積分降維解法！』
- **`D1 3.2`**：學員乙在黑板證明重根定理，導師質詢：『如果 $P(x_0)=P'(x_0)=P''(x_0)=0$，差函數幾何圖像在 $x_0$ 附近是什麼樣子？它與切線是相交、相切還是相穿？』
- **`D1 3.3`**：學員丙被要求在黑板上繪製曲線 $y = x^{1/3}$ 在原點附近的圖像，並論辯為何此處切線垂直於 $x$ 軸，斜率不存在但切線依然嚴格存在。

##### 2. 未知自然科學情境破局題（Unseen Sandbox Scenarios, 3 題）
- **`D2 3.1`**：航天器軌道轉移霍曼軌道，軌道曲線在近日點與遠日點分別與圓軌道相切，現場寫出二階接觸（曲率半徑相同）的微積分代數條件。
- **`D2 3.2`**：給定四次勢阱 $V(x) = ax^4 - bx^2$，粒子總能量為 $E$，在相空間中作圖，現場構造能量面與勢能面相切時質點速度為零之臨界條件。
- **`D2 3.3`**：機器人機械臂末端運動軌跡曲線，要求在避障路徑轉角處達到 $C^2$ 平滑（切線方向與曲率均連續），構造樣條多項式相切方程。

##### 3. 體制內聯考大題降維秒殺題（System Trivialization Arsenal, 3 題）
- **`D3 3.1`**：高中聯考幾何壓軸題：求過點 $P(1, 0)$ 且與曲線 $y = x^3 - 2x + 1$ 相切的全部直線方程。傳統待定係數需解三次方程判別式，以切點代數方程 3 行求出切點 $x=-1$ 與 $x=1$。

## 第三篇：Stage II：複合映射、隱函數與相空間（Topics 4–6）

### Topic 4：尺度轉換齒輪與量綱連鎖律（尺規比率與連乘本質）

> **🥋 道場研討核心（Dojo Core Mission）**：黑板直擊：以不同坐標系尺規轉換（英吋對公分、攝氏對華氏、空間尺度收縮）現場搭建連鎖微商矩陣，導師當場抓捕學員漏乘內層導數的隱性思維惰性。

#### 黑板板書必演 7 條核心公式鏈
- **`Brd 4.1`【複合映射連鎖律核心定理式】**：$$\frac{\mathrm{d}}{\mathrm{d}x} f\big(g(x)\big) = f'\big(g(x)\big) \cdot g'(x)$$

- **`Brd 5.5`【橢圓切線點斜式代數閉環式】**：$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \implies \frac{x x_0}{a^2} + \frac{y y_0}{b^2} = 1 \quad (\text{切線方程直接映射})$$
- **`Brd 5.6`【鉛直切線奇異性判據式】**：$$F_y(x_0, y_0) = 0 \quad \text{且} \quad F_x(x_0, y_0) \neq 0 \iff \text{切線斜率發散，切線為垂直直線}$$
- **`Brd 5.7`【二階隱微分曲率分子展開式】**：$$y'' = -\frac{F_{xx} F_y^2 - 2F_{xy}F_x F_y + F_{yy}F_x^2}{F_y^3}$$

#### 黑板板書必演 7 條核心公式鏈

- **`Brd 8.2`【基底向量旋轉微商基本式】**：$$\frac{\mathrm{d}\hat{\mathbf{r}}}{\mathrm{d}t} = \dot{\theta}\hat{\boldsymbol{\theta}}, \quad \frac{\mathrm{d}\hat{\boldsymbol{\theta}}}{\mathrm{d}t} = -\dot{\theta}\hat{\mathbf{r}}$$

- **`Brd 8.5`【等速圓周向心加速度封閉解】**：$$r = R, \dot{r}=0, \dot{\theta}=\omega \implies \mathbf{a} = -R\omega^2\hat{\mathbf{r}} = -\frac{v^2}{R}\hat{\mathbf{r}}$$
- **`Brd 8.6`【科里奧利加速度微分項】**：$$\mathbf{a}_{\text{coriolis}} = 2\dot{r}\dot{\theta}\hat{\boldsymbol{\theta}} = 2\boldsymbol{\omega} \times \mathbf{v}_{\text{rel}}$$
- **`Brd 8.7`【克卜勒面積速度常數微商守恆式】**：$$\frac{\mathrm{d}A}{\mathrm{d}t} = \frac{1}{2}r^2\dot{\theta} = \frac{L}{2m} = \text{const} \iff a_\theta = 0$$

- **`Brd 10.2`【黎曼和矩形面積疊加定義式】**：$$S_n = \sum_{k=1}^n f(x_k^*) \Delta x \quad (x_k^* \in [x_{k-1}, x_k])$$

- **`Brd 10.4`【拋物線阿基米德自然數平方和展開式】**：$$\sum_{k=1}^n k^2 = \frac{n(n+1)(2n+1)}{6} = \frac{1}{3}n^3 + \frac{1}{2}n^2 + \frac{1}{6}n$$
- **`Brd 10.5`【單項式平方定積分極限手算式】**：$$\int_0^1 x^2\,\mathrm{d}x = \lim_{n \to \infty} \sum_{k=1}^n \left(\frac{k}{n}\right)^2 \frac{1}{n} = \lim_{n \to \infty} \frac{n(n+1)(2n+1)}{6n^3} = \frac{1}{3}$$
- **`Brd 10.6`【定積分線性與區間可加公理式】**：$$\int_a^b \big(\alpha f + \beta g\big)\,\mathrm{d}x = \alpha \int_a^b f\,\mathrm{d}x + \beta \int_a^b g\,\mathrm{d}x, \quad \int_a^b f = \int_a^c f + \int_c^b f$$
- **`Brd 10.7`【可積性達布上下和收斂充要條件】**：$$\lim_{\|P\| \to 0} \big(U(P, f) - L(P, f)\big) = 0 \iff f \in \mathcal{R}[a, b]$$

### Topic 11：微積分基本定理（FTC）：對偶統一（變化率與積聚的合流）

> **🥋 道場研討核心（Dojo Core Mission）**：黑板直擊：在黑板上以面積函數 $A(x) = \int_a^x f(t)\,\mathrm{d}t$ 的增量 $\Delta A \approx f(x)\Delta x$ 為核心，實彈演示除以 $\Delta x$ 後取極限 $A'(x)=f(x)$ 的神級幾何代數轉譯，徹底融通兩大算子。

#### 黑板板書必演 7 條核心公式鏈
- **`Brd 11.1`【變上限積分累積函數定義式】**：$$F(x) = \int_a^x f(t)\,\mathrm{d}t \quad (x \in [a, b])$$
- **`Brd 11.2`【變上限函數微元面積增量式】**：$$\Delta F = F(x + \Delta x) - F(x) = \int_x^{x+\Delta x} f(t)\,\mathrm{d}t = f(c) \Delta x \quad (c \in [x, x+\Delta x])$$
- **`Brd 11.3`【微積分第一基本定理（FTC-1）】**：$$\frac{\mathrm{d}}{\mathrm{d}x} \left( \int_a^x f(t)\,\mathrm{d}t \right) = f(x) \quad (f \text{ 在 } x \text{ 處連續})$$
- **`Brd 11.4`【牛頓-萊布尼茲第二基本定理（FTC-2）】**：$$\int_a^b f(x)\,\mathrm{d}x = F(b) - F(a) = \big[ F(x) \big]_a^b \quad (F'(x) = f(x))$$
- **`Brd 11.5`【廣義變限積分連鎖求導式】**：$$\frac{\mathrm{d}}{\mathrm{d}x} \left( \int_{u(x)}^{v(x)} f(t)\,\mathrm{d}t \right) = f\big(v(x)\big) v'(x) - f\big(u(x)\big) u'(x)$$
- **`Brd 11.6`【位移速度加速度三位一體合流式】**：$$x(t) - x(t_0) = \int_{t_0}^t v(\tau)\,\mathrm{d}\tau, \quad v(t) - v(t_0) = \int_{t_0}^t a(\tau)\,\mathrm{d}\tau$$
- **`Brd 11.7`【不連續點 FTC 局部失效檢驗式】**：$$f(x) = \operatorname{sgn}(x) \implies F(x) = |x| \implies F'(0) \text{ 不存在} \neq f(0) = 0$$

#### 黑板板書必演 7 條核心公式鏈
- **`Brd 28.1`【週期信號均方根（RMS）微積分定義式】**：$$V_{\text{rms}} = \sqrt{\frac{1}{T}\int_0^T V(t)^2\,\mathrm{d}t}$$
- **`Brd 28.2`【正弦交流電峰值與有效值根號二關係式】**：$$\int_0^T \sin^2(\omega t)\,\mathrm{d}t = \frac{T}{2} \implies V_{\text{rms}} = \frac{V_0}{\sqrt{2}} \implies V_0 = 110\sqrt{2} \approx 155.6\,\text{V}$$
- **`Brd 28.3`【交流電網平均功率與功率因數定積分式】**：$$P_{\text{avg}} = \frac{1}{T}\int_0^T V(t)I(t)\,\mathrm{d}t = V_{\text{rms}} I_{\text{rms}} \cos\phi$$
- **`Brd 28.4`【量子波函數波恩機率密度統計詮釋式】**：$$\mathrm{d}P = |\psi(x)|^2\,\mathrm{d}x, \quad \int_{-\infty}^{\infty} |\psi(x)|^2\,\mathrm{d}x = 1$$
- **`Brd 28.5`【量子力學物理量算子期望值一階矩積分式】**：$$\langle x \rangle = \int_{-\infty}^\infty x |\psi(x)|^2\,\mathrm{d}x, \quad \langle p \rangle = \int_{-\infty}^\infty \psi^*(x)\left(-i\hbar\frac{\mathrm{d}}{\mathrm{d}x}\right)\psi(x)\,\mathrm{d}x$$
- **`Brd 28.6`【量子方差二階矩定積分式】**：$$(\Delta x)^2 = \langle x^2 \rangle - \langle x \rangle^2 = \int_{-\infty}^\infty (x - \langle x \rangle)^2 |\psi(x)|^2\,\mathrm{d}x$$
