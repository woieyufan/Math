3.1 切線代數重根定理與判別式等價性

國中代數使用判別式 $\Delta = b^2 - 4ac = 0$ 判斷切線，本質是聯立方程後代數重根的特例，僅適用於二次拋物線。當遇到三次曲線反曲點切線時，切線會「直接穿過曲線」，國中方法徹底失效。

微積分公理規定：曲線 $y = f(x)$ 與直線 $y = L(x) = f'(x_0)(x - x_0) + f(x_0)$ 在 $x = x_0$ 處切觸的充要條件，是其聯立差式必定可被因式分解為：

$$f(x) - L(x) = (x - x_0)^2 \cdot Q(x)$$

即切點處至少具備代數二重根；若 $x_0$ 為反曲點，則差式具備三重根 $(x - x_0)^3$。

3.2 狀態相空間微商 $a = v\frac{dv}{dx}$ 與費馬時間極值原理

在古典運動學中，時間 $t$ 往往是非必要的冗餘變數。根據連鎖律微商變換：

$$a = \frac{dv}{dt} = \frac{dv}{dx} \frac{dx}{dt} = v \frac{dv}{dx}$$

量綱驗證：$[a] = [v] \cdot [v][L]^{-1} = [L T^{-1}] \cdot [L T^{-1} L^{-1}] = [L T^{-2}]$，量綱嚴格守恆。

在幾何光學中，費馬原理規定光沿傳播時間最短之路徑前進。光在介質界面傳播時間函數為 $t(x) = \frac{\sqrt{x^2 + d_1^2}}{v_1} + \frac{\sqrt{(L-x)^2 + d_2^2}}{v_2}$。對空間坐標求一階導數極值：

$$\frac{dt}{dx} = \frac{x}{v_1 \sqrt{x^2 + d_1^2}} - \frac{L-x}{v_2 \sqrt{(L-x)^2 + d_2^2}} = \frac{\sin\theta_1}{v_1} - \frac{\sin\theta_2}{v_2} = 0$$

直接純代數演繹出斯乃爾折射定律 $n_1 \sin\theta_1 = n_2 \sin\theta_2$。

3.3 動能量綱通用微分式 $dE = v\,dp$：物質三角形積分 vs 光子矩形積分

做功微元的通用力學定義為：

$$dW = F\,dx = \frac{dp}{dt}dx = \frac{dx}{dt}dp = v\,dp$$

能量增量恆等於速度對動量的積分 $dE = v\,dp$。

1
低速宏觀物質：速度與動量成正比 $v = \frac{p}{m}$。在 $(p, v)$ 相空間中，積分路徑為通過原點的斜直線，覆蓋面積為直角三角形：
$$E_k = \int_0^p v\,dp = \int_0^p \frac{p}{m}\,dp = \frac{1}{2m} p^2 = \frac{1}{2}mv^2$$

公式中必然出現係數 $\frac{1}{2}$ 的幾何本質，是相空間直角三角形面積。

2
無靜止質量光子：速度恆為真空中光速 $v = c$（常數）。在 $(p, v)$ 相空間中，積分路徑為水平直線，覆蓋面積為長方形：
$$E = \int_0^p c\,dp = c \int_0^p dp = pc$$

光子能量 $E=pc$ 係數必為 1，其幾何本質是相空間長方形面積。

3.4 交流電正弦平方降冪定積分與 110V 峰值 156V

正弦信號 $V(t) = V_0 \sin(\omega t)$ 在一個完整週期 $T = \frac{2\pi}{\omega}$ 內的算術平均值恆為零。工程上有效值定義為電阻純做功發熱量定積分之方均根（Root-Mean-Square, RMS）：

$$V_{\text{rms}}^2 = \frac{1}{T} \int_0^T V(t)^2\,dt = \frac{V_0^2}{T} \int_0^T \sin^2(\omega t)\,dt$$

利用三角恆等降冪公式 $\sin^2\theta = \frac{1 - \cos(2\theta)}{2}$：

$$V_{\text{rms}}^2 = \frac{V_0^2}{2T} \left[ \int_0^T 1\,dt - \int_0^T \cos(2\omega t)\,dt \right] = \frac{V_0^2}{2T} [T - 0] = \frac{V_0^2}{2} \implies V_{\text{rms}} = \frac{V_0}{\sqrt{2}}$$

因此台灣家用插座交流電標稱 $110\text{ V}$，其瞬間最大峰值實為 $V_0 = 110 \times \sqrt{2} \approx 155.56\text{ V}$。

3.5 連續機率密度（PDF/CDF）的 FTC 映射與馬克士威-波茲曼活化能尾部積分

累積機率分佈函數 $F(x)$ 與機率密度函數 $f(x)$ 透過微積分基本定理（FTC）對偶相連：

$$F(x) = \int_{-\infty}^x f(u)\,du \iff f(x) = \frac{dF}{dx}$$

化學反應速率方程中，有效碰撞分子佔比並非取決於平均動能，而是取決於動能超過活化能閾值 $E_a$ 的分子佔比。馬克士威-波茲曼速率分佈的高能尾部定積分為：

$$P(E \ge E_a) = \int_{E_a}^\infty f_{\text{MB}}(E)\,dE \propto e^{-\frac{E_a}{k_B T}}$$

當溫度微升 $\Delta T = 10\text{ K}$ 時，平均動能 $\frac{3}{2}k_B T$ 僅微增約 $3\%$，但指數尾部覆蓋的幾何積分面積暴增 $200\% \sim 300\%$。這徹底揭開了中學化學教科書未解之世紀懸案。

3.6 近代物理波函數歸一化與測不準原理的方差本質

量子力學中，微觀粒子的空間波函數 $\psi(x)$ 之模方 $|\psi(x)|^2$ 即為空間位置之連續機率密度函數，滿足空間歸一化公理：

$$\int_{-\infty}^\infty |\psi(x)|^2\,dx = 1$$

位置期望值 $\langle x \rangle = \int x |\psi|^2 dx$（第一矩），位置方差 $\sigma_x^2 = \int (x - \langle x \rangle)^2 |\psi|^2 dx$（第二中心矩）。動量空間波函數 $\phi(p)$ 是 $\psi(x)$ 的傅立葉變換對偶。根據柯西-施瓦茨不等式與傅立葉變換的頻寬定理，任何波包之空間標準差與動量標準差乘積必然滿足純數學下限：

$$\sigma_x \cdot \sigma_p \ge \frac{\hbar}{2}$$

這在公理層面為海森堡測不準原理正名：測不準絕非測量儀器碰撞電子的物理干擾，而是波包分佈標準差的純數學下限。
