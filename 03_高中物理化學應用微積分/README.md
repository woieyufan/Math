## 體系三大組成模組

### 一、 專著出版正文與階梯解答（`專著正文與詳細解答/`）
- **《中學微積分先修專著》第一章正文與解答**：
  - 核心哲學：以直代曲、割線極限、無窮小代數消去未定式。
  - 配套標準五步法 SOP 解題規範手冊與階梯題庫解答。
- **《AI 工具鏈與編輯原則規範手冊》**：
  - 嚴格界定「去說教感」、「四拍首尾閉環」、「動機鋪陳鏈」與「難度對齊律」。

### 二、 頂層白皮書與出版工程藍皮書（`體系白皮書與工程藍皮書/`）
- **《中學超前自學·微積分先修體系白皮書（第一性原理綱領）》**：
  - 四大基石憲章：因果自洽與零賒帳原則、大一統融會原則、螺旋式深化原則、分析力學升維原則。
- **《專著出版工程藍皮書·書籍篇》**：
  - 全書 7 大篇、28 個完整章節、196 條核心演繹公式、448 道階梯習題。
  - 全面覆蓋高中物理必背公式之微積分推導：
    - 運動學微分、動能定理相空間積分、一階常微分方程（火箭噴射齊奧爾科夫斯基方程、流體阻力）

    - 熱力學絕熱過程 $PV^\gamma = C$、電磁學畢奧-薩伐爾磁場積分、轉動慣量微元
    - 化學動力學反應速率方程式（零級、一級、二級反應與半衰期）
    - 二重極座標高斯常態分佈閉環、馬克士威氣體分子速率分佈、量子測不準原理大一統。
- **《課堂篇與細節工程指引》**：
  - 雙軌制「案頭書籍研讀 + 黑板道場研討」之標準教研 SOP。
